💻 服务器初始化与保活指令集

1. 一键系统体检

快速查看系统的操作系统、CPU、内存和硬盘使用情况。

echo "== 系统 =="; cat /etc/os-release | grep "PRETTY_NAME"; echo "== CPU =="; lscpu | grep "Model name" | head -1; echo "核心: $(nproc)"; echo "== 内存 =="; free -h; echo "== 硬盘 =="; df -h /

2. 科技lion 一键安装

在纯净的 Ubuntu/Debian 环境中一键安装科技lion面板（需 root 权限）。

bash <(curl -sL kejilion.sh)

3. Simular Box 极简保活 (Cron)

通过系统自带的 Cron 定时任务，每 10 分钟请求一次网络，防止云电脑判定为闲置休眠。

# 1. 安装 cron
apt update && apt install -y cron

# 2. 写入定时任务（每 10 分钟请求一次百度）
echo "*/10 * * * * curl -s -o /dev/null http://www.baidu.com" | crontab -

# 3. 强行启动 cron 服务（沙盒环境专用）
systemctl start cron
⚠️ 沙盒环境提示：
在 Simular Box 这类沙盒环境里，执行 apt install cron 后，系统出于安全策略通常会禁止自动启动服务。因此必须手动执行 systemctl start cron 才能让它真正跑起来。

4. 验证保活是否生效

运行以下命令查看任务是否已写入，并观察日志确认它是否在准时执行。

# 查看任务列表（看到 */10 * * * * curl... 就说明写进去了）
crontab -l

# 实时查看 cron 日志（沙盒环境没有 syslog，用这个）
journalctl -u cron -f
💡 日志解读：
如果你在日志里看到类似 (root) CMD (curl -s -o /dev/null http://www.baidu.com)，就代表你的定时任务已经完美生效。按 Ctrl + C 即可退出日志查看。
