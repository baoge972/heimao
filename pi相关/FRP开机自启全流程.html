🔧 FRP 开机自启配置

🖥️ 云服务器（FRP 服务端）

实际路径：/root/frp_0.69.1_linux_amd64/

第一步：创建 systemd 服务文件

sudo nano /etc/systemd/system/frps.service

第二步：粘贴以下内容

[Unit] Description=FRP Server After=network.target [Service] Type=simple WorkingDirectory=/root/frp_0.69.1_linux_amd64 ExecStart=/root/frp_0.69.1_linux_amd64/frps -c /root/frp_0.69.1_linux_amd64/frps.toml Restart=on-failure RestartSec=5 [Install] WantedBy=multi-user.target

第三步：启用开机自启

sudo systemctl enable frps
✅ 验证方法：
sudo systemctl status frps
看到 active (running) 即为成功。

💻 本地电脑（FRP 客户端）

实际路径：D:\frp\

第一步：确认 run.vbs 内容

在 D:\frp\ 目录下，run.vbs 的实际内容如下：

' 杀掉所有 frpc 进程 CreateObject("WScript.Shell").Run "taskkill /F /IM frpc.exe", 0, True ' 杀掉所有 cmd 进程（关闭弹窗） CreateObject("WScript.Shell").Run "taskkill /F /IM cmd.exe", 0, True ' 等待 1 秒 WScript.Sleep 1000 ' 后台启动 frpc（无窗口） CreateObject("WScript.Shell").Run "D:\frp\frpc.exe -c D:\frp\frpc.toml", 0, False

第二步：创建快捷方式

  • 进入 D:\frp\ 文件夹
  • 右键 run.vbs → 点击“创建快捷方式”

第三步：放入启动文件夹

  • 按 Win + R，输入 shell:startup，回车
  • 把刚才创建的快捷方式复制进去
✅ 验证方法：
重启电脑，打开任务管理器（Ctrl+Shift+Esc），在进程列表中找到 frpc.exe 即为成功。
