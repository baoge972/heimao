📊 服务器检测脚本 baoge.sh

一个轻量级服务器检测脚本，一键生成包含 CPU、内存、硬盘、端口、Docker、服务、防火墙、已部署项目清单等 13 项信息的全面报告。

📋 检测内容

编号检测项说明
1系统信息操作系统版本、内核、运行时间
2CPU 信息型号、核心数、架构
3内存信息总内存、已用、可用、Swap
4硬盘信息分区和使用率
5端口占用所有已占用端口列表
6Docker 容器所有容器的状态和端口映射
7已部署项目清单自动识别 Docker/手动/Nginx 反代项目
8运行服务systemd 管理的服务列表
9Nginx 站点已配置的站点和域名（同时支持宿主机+Docker）
10防火墙状态UFW/iptables 状态
11公网 IP当前服务器的公网 IP
12资源占用 TOPCPU 和内存占用最高的进程
13快速总结核心指标 + 建议

🚀 三种使用方式

方式一 直接创建并执行（推荐）

适用场景：单台服务器，想要快速运行检测

curl -sL https://git.baoge.wang/baoge.sh | sed s/\r$// > baoge.sh && chmod +x baoge.sh && ./baoge.sh
💡 从远程拉取脚本，自动处理换行符，保存为 baoge.sh 并执行。以后直接执行 ./baoge.sh 即可。

方式二 直接运行（不保存文件）

适用场景：一次性检测，不想要脚本文件

curl -sL https://git.baoge.wang/baoge.sh | sed 's/\r$//' | PATH=/usr/bin:/bin:/usr/sbin:/sbin bash
💡 说明：PATH=... 用于确保脚本在精简系统（如 Alpine）中能正常找到 uniq 等基础命令。如果您的系统是 Ubuntu/Debian，通常无需额外操作。

方式三 安装 dos2unix 后运行

适用场景：多台服务器，愿意安装 dos2unix

第一步：安装 dos2unix

apt update && apt install dos2unix -y

第二步：执行脚本

curl -sL https://git.baoge.wang/baoge.sh | dos2unix | bash
💡 安装 dos2unix 后，脚本的换行符问题由工具自动处理。以后直接执行第二步即可，无需重复安装。

📌 使用说明

1根据您的场景选择上面一种方式
2复制对应的命令，粘贴到终端按回车执行
3等待脚本自动完成，查看生成的报告

📌 后续使用

如果使用方式一创建了文件，以后再次检测只需执行：

./baoge.sh

📌 保存报告到文件

./baoge.sh > server_report_$(date +%Y%m%d_%H%M%S).txt

⚠️ 常见问题

Q: 提示 "Permission denied"？
执行 chmod +x baoge.sh 添加执行权限即可。
Q: 报错 "sed: unknown option to 's'"？
使用方式二或方式三，通过 sed 或 dos2unix 转换换行符解决。
Q: 在 Alpine Linux 上执行报错 uniq: not found？
Alpine 默认不包含 GNU coreutils，需要手动安装：
apk add coreutils
安装后重新执行方式二的命令即可。
⚠️ 注意：
需要在 root 用户 或具有 sudo 权限 的用户下执行，否则部分信息无法完整显示。
