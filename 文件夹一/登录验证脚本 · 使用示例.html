🔐 登录验证脚本 · 使用教程

用于 Cloudflare Workers 的页面密码验证 · 环境变量注入 · 记住登录

一、脚本功能

  • ✅ 从 Cloudflare Workers 环境变量读取密码（ADMIN_PASSWORD）
  • ✅ 记住登录（localStorage 存储，刷新不重新输入）
  • ✅ 回车键快捷登录
  • ✅ 全屏遮罩 + 渐变背景

三、插入位置

2 将脚本放入 Workers 代码

把复制好的脚本，放到 Workers 的 return new Response(`...`) 中的 <body> 开头位置：

export default { async fetch(request, env) { // 读取环境变量 const ADMIN_PASSWORD = env.ADMIN_PASSWORD || '123456'; return new Response(`<!DOCTYPE html> <html> <head> <title>我的页面</title> </head> <body> <!-- ========== 登录验证脚本 开始 ========== --> // 粘贴复制的脚本代码 <!-- ========== 登录验证脚本 结束 ========== --> <!-- 您原有的页面内容 --> <div id="app">...</div> </body> </html>`, { headers: { "content-type": "text/html;charset=UTF-8" } }); } };
⚠️ fetch(request, env) 必须带 env 参数。

六、常见问题

Q1 输入正确密码提示错误？
  • 检查环境变量 ADMIN_PASSWORD 是否设置，变量名是否拼写正确
  • 检查 fetch(request, env) 是否漏掉了 env 参数
  • 在 Worker 控制台执行 console.log(env.ADMIN_PASSWORD) 验证
Q2 刷新后要重新登录？

将脚本中的 REMEMBER_LOGIN 改为 true。

Q3 遮罩不消失？
  • 在 Cloudflare Workers Dashboard 中，把环境变量 ADMIN_PASSWORD 的值改成 123456
  • 重新部署，输入 123456 测试
  • 如果能进去 → 原来设置的密码不对，重新设置正确密码
  • 如果进不去 → 检查 fetch(request, env) 是否漏掉了 env 参数
Q4 可以自定义背景图吗？

修改脚本中 #login_overlay 的 background 属性，替换图片 URL。
