🧭 极光导航 · 本地 PM2 部署教程

让导航页在 Windows 后台持续运行，关掉 VS Code / 终端也不受影响

1 安装 PM2

PM2 是一个进程管理器，能让 Node.js 程序在后台持续运行。

PowerShell npm install -g pm2
✅ 如果提示 npm 找不到，请先安装 Node.js（v18+）

2 进入项目目录

在终端中进入你的项目文件夹。

PowerShell cd D:\记事本\jiguang-navigation
⚠️ 路径根据你实际存放的位置修改

3 创建启动文件 start.mjs

由于项目使用了 "type": "module"，需要用 ES Module 语法。

PowerShell @" import { spawn } from 'child_process'; const child = spawn('npm', ['run', 'dev', '--', '-p', '3006'], { stdio: 'inherit', shell: true }); "@ | Out-File -FilePath start.mjs -Encoding utf8
💡 这个文件会在后台运行 npm run dev，端口为 3006

4 用 PM2 启动

PowerShell pm2 start start.mjs --name "jiguang" --interpreter node
✅ 看到 online 状态就说明成功了

5 查看运行状态

PowerShell pm2 status

6 访问导航页

打开浏览器，输入以下地址：

http://localhost:3006

登录账号：admin  ·  密码：123456

🔧 常用管理命令

pm2 status
查看所有进程状态
pm2 logs jiguang
查看项目运行日志
pm2 stop jiguang
停止项目（保留进程）
pm2 start jiguang
重新启动已停止的进程
pm2 restart jiguang
重启项目
pm2 delete jiguang
彻底删除进程

💾 保存进程列表（开机自启准备）

保存当前 PM2 进程列表，用于开机恢复。

PowerShell pm2 save

🖥️ Windows 开机自启配置

PM2 的 pm2 startup 在 Windows 上不支持，需要用任务计划程序或启动脚本。

方法一：启动脚本（推荐）

PowerShell $startupPath = "$env:USERPROFILE\AppData\Roaming\Microsoft\Windows\Start Menu\Programs\Startup" @" @echo off cd /d D:\记事本\jiguang-navigation pm2 resurrect "@ | Out-File -FilePath "$startupPath\jiguang.bat" -Encoding ascii

方法二：任务计划程序

  1. 按 Win + R，输入 taskschd.msc，回车
  2. 点击右侧 创建基本任务
  3. 名称：极光导航
  4. 触发器：当计算机启动时
  5. 操作：启动程序
  6. 程序：C:\Program Files\nodejs\node.exe
  7. 参数：D:\记事本\jiguang-navigation\node_modules\.bin\next dev -p 3006
  8. 起始于：D:\记事本\jiguang-navigation
  9. 完成

⚠️ 注意事项

💡 每次修改代码后
需要 重启 才能生效：
pm2 restart jiguang
🖥️ 端口占用
如果 3006 端口被占用，修改 start.mjs 中的 -p 3006 为其他端口
✅ 成功标志
执行 pm2 status 看到 online，访问 http://localhost:3006 能看到页面，就说明部署成功了！
