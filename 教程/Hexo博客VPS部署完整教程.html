📡 Hexo 静态网站部署完整教程
基于 Nginx + Python HTTP Server + SSL (Let's Encrypt)

✅ 实战记录 · 宝哥服务器 🔧 适用: Hexo / Hugo / VuePress / 任何静态站点 🖥️ 系统: Ubuntu 22.04 / 20.04

本文档记录了在 VPS (8.217.131.234) 上完整部署 Hexo 静态网站的步骤，包括 Python 静态服务器、Nginx 反向代理、域名绑定、SSL 证书自动申请。命令均附带「一键复制」按钮，下次有类似项目可直接复用。

1️⃣ 准备工作

确认服务器环境与网站文件

# 查看当前服务器公网 IP
curl -4 ifconfig.me

# 进入站点根目录 (假设网站文件放在 /root/hexo)
cd /root/hexo
ls -la   # 应包含 index.html, css, js 等静态文件
💡 如果还没有生成静态文件，请在本地先用 hexo generate 构建，然后将 public/ 目录内容上传到服务器目录（例如 /root/hexo）。

2️⃣ 启动简易 HTTP 服务 (Python)

使用 Python 自带模块在 8080 端口提供静态文件访问，作为后端源站。

# 进入静态文件目录
cd /root/hexo

# 后台启动 HTTP 服务 (端口 8080)
nohup python3 -m http.server 8080 > /dev/null 2>&1 &

# 验证服务是否正常
curl -I http://127.0.0.1:8080
📌 说明：nohup 保证退出终端后服务继续运行，端口可自定义（如 8080, 3000等）。务必确保端口未被占用且防火墙允许。

3️⃣ 配置 Nginx 反向代理 (HTTP 阶段)

先配置 HTTP 访问，验证连通性后再升级 HTTPS。

# 创建 Nginx 配置文件 (将域名替换为你自己的)
cat > /etc/nginx/conf.d/hexo.baoge123.de5.net.conf << 'EOF'
server {
    listen 80;
    server_name hexo.baoge123.de5.net;   # 替换为真实域名

    location / {
        proxy_pass http://127.0.0.1:8080;
        proxy_http_version 1.1;
        proxy_set_header Host $host;
        proxy_set_header X-Real-IP $remote_addr;
        proxy_set_header X-Forwarded-For $proxy_add_x_forwarded_for;
        proxy_set_header X-Forwarded-Proto $scheme;
    }
}
EOF

# 测试 Nginx 配置并重载
nginx -t && systemctl reload nginx

# 测试 HTTP 访问 (域名需已解析到服务器 IP)
curl -I http://hexo.baoge123.de5.net
🌐 确保域名已添加 A 记录指向服务器 IP，否则证书申请与访问会失败。可用 dig 域名 +short 验证。

4️⃣ 申请 SSL 证书 & 启用 HTTPS

使用 Let's Encrypt 免费证书，通过 certbot 自动颁发并配置。

# 停止 Nginx (standalone 模式需要占用 80 端口)
systemctl stop nginx

# 申请证书 (将邮箱和域名替换为真实值)
certbot certonly --standalone -d hexo.baoge123.de5.net \
  --non-interactive --agree-tos --email admin@baoge123.de5.net

# 证书成功后会存放在 /etc/letsencrypt/live/域名/ 目录
# 更新 Nginx 配置，启用 HTTPS + HTTP 自动跳转
cat > /etc/nginx/conf.d/hexo.baoge123.de5.net.conf << 'EOF'
server {
    listen 80;
    server_name hexo.baoge123.de5.net;
    return 301 https://$server_name$request_uri;
}

server {
    listen 443 ssl http2;
    server_name hexo.baoge123.de5.net;

    ssl_certificate /etc/letsencrypt/live/hexo.baoge123.de5.net/fullchain.pem;
    ssl_certificate_key /etc/letsencrypt/live/hexo.baoge123.de5.net/privkey.pem;

    location / {
        proxy_pass http://127.0.0.1:8080;
        proxy_http_version 1.1;
        proxy_set_header Host $host;
        proxy_set_header X-Real-IP $remote_addr;
        proxy_set_header X-Forwarded-For $proxy_add_x_forwarded_for;
        proxy_set_header X-Forwarded-Proto $scheme;
    }
}
EOF

# 启动 Nginx 并测试
systemctl start nginx
nginx -t && systemctl reload nginx

# 验证 HTTPS 是否生效
curl -I https://hexo.baoge123.de5.net

5️⃣ 部署脚本 & 日常更新方法 (只传 public)

为避免每次上传整个 hexo 目录覆盖主题配置，推荐仅上传生成的静态文件并保留服务器上的 Nginx 与 Python 服务。

# 在本地电脑生成静态文件后，使用 scp 上传 public 内容
# 示例（本地执行）：
cd ~/my-blog           # 你的 hexo 项目目录
hexo clean && hexo generate
scp -r public/* root@8.217.131.234:/root/hexo/

# 服务器端无需重启，Nginx 自动代理最新文件 (Python http.server 会自动读取新内容)
# 若需重启 python 服务，可执行：
pkill -f "python3 -m http.server 8080"
cd /root/hexo && nohup python3 -m http.server 8080 > /dev/null 2>&1 &
🔁 这种模式的好处：服务器上的主题文件（anzhiyu/_config.yml）从不需要变动，所有修改都在本地 hexo 源码中进行，每次 `hexo generate` 后上传 public 目录即可。播放器、样式等定制永久保留。

7️⃣ 完整项目架构总结

  • 本地开发：Hexo 源码 + 主题 (anzhiyu) + 文章 Markdown
  • 生成静态文件：hexo generate 产出 public 目录
  • 上传至服务器：scp -r public/* root@你的IP:/root/hexo
  • 服务器静态服务：Python HTTP Server 监听 8080 提供文件
  • Web 网关：Nginx 监听 80/443 并将请求代理到 127.0.0.1:8080
  • 证书管理：Let's Encrypt 自动续期，保证 HTTPS 安全
⚡ 优势：一次配置，永久使用。后续更新网站只需上传 public 内容，无需再次操作 Nginx 或证书，主题/播放器配置永不丢失。

8️⃣ 一键准备完整环境 (针对空服务器)

如果全新服务器，可以一次性安装 Nginx、Python、Certbot。

# 更新系统并安装必要软件
sudo apt update && sudo apt install -y nginx python3 certbot

# 确保 Nginx 启动
systemctl enable nginx
systemctl start nginx

# 创建站点根目录
mkdir -p /root/hexo
