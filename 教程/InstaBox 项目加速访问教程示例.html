🚀 InstaBox 青龙面板极速访问教程

本教程采用 “Cloudflare Worker 路由 + CNAME 优选 IP” 的方案，无需点亮小黄云，即可实现隐藏源站与加速访问。

准备工作

  • 一个已经部署好并发布的 青龙面板（拿到其原始的 https://xxx.instabox.tech 地址）。
  • 一个托管在 Cloudflare 的 自定义域名（例如 ql.你的域名.com）。

第一步：配置 Worker 代码

  1. 进入 Cloudflare 控制台，打开你的 Worker 编辑器。
  2. 将以下代码完整复制并覆盖进去。
  3. 务必修改代码中的 你的青龙真实域名（不要带 https://，也不要有末尾斜杠）。
addEventListener("fetch", event => {
  event.respondWith(handleRequest(event.request));
});

async function handleRequest(request) {
  let url = new URL(request.url);
  
  // 【修改这里】填入你 InstaBox 分配的青龙真实域名（不要带 https://）
  url.hostname = "你的青龙真实域名.instabox.tech"; 

  let newRequest = new Request(url, {
    method: request.method,
    headers: request.headers,
    body: request.method !== 'GET' && request.method !== 'HEAD' ? request.body : null,
    redirect: 'manual'
  });

  return fetch(newRequest);
}

点击右上角 “保存并部署”。

第二步：添加自定义域和路由

  1. 在 Worker 页面，点击 “设置” -> “触发器”。
  2. 找到 “自定义域”，点击 “添加自定义域”，填入你要加速的域名（如 ql.你的域名.com）。
  3. 在同一页面找到 “路由”，点击 “添加路由”：
    • 路由 填：你的自定义域名/*（比如 ql.你的域名.com/*）
    • 区域 选择你的主域名

第三步：配置 DNS 解析（关键）

去你的 DNS 解析后台（支持 CNAME 优选 IP 的那个后台），添加解析：

  • 记录类型：CNAME
  • 主机记录/名称：ql（或者你定的前缀）
  • 记录值/目标：cf.090227.xyz（或你正在用的优选 IP 域名）
  • 代理状态：保持 “仅 DNS”（不要点亮小黄云）。
⚠️ 提醒： 这里的目标只填优选域名（如 cf.090227.xyz），千万千万不要在这里填你 InstaBox 的青龙地址！青龙地址只写在第一步的 Worker 代码里。

第四步：访问测试

在浏览器输入 https://你的自定义域名 访问。只要能正常加载青龙面板并登录，代表配置成功。
