🛡️ InstaBox 终极保活教程

本教程适用于已拥有一台外部常开设备（如 RackNerd VPS、NAS、软路由等）的用户。通过外部脚本，不仅解决 30 分钟闲置暂停，还能破解 8 小时强制暂停，实现无限接近 24 小时在线。

⚠️ 注意事项： InstaBox 为免费沙盒平台，官方随时可能调整风控策略（如限制端口、缩短强制停机时间等）。请勿在机器上跑高负载任务或存放重要数据，仅作学习测试之用。

第一步：获取 API 密钥

  1. 登录 InstaBox 控制台，进入 API Keys 页面。
  2. 点击 Create API Key。
  3. Key Name 随便填（如 keepalive）。
  4. Expires 留空（永不过期）。
  5. Permissions 选择 Restricted，并在下方勾选 Machines 的 Write 权限。
  6. 点击 Create，复制生成的 ibk_ 开头的密钥。注意：密钥只显示一次。

第二步：在外部 VPS 上安装保活脚本

SSH 连接到你的常开设备（如你的 RackNerd VPS），复制下方命令并执行：

注意：将命令中的 ibk_xxx 替换为你刚复制的真实密钥，key= 和密钥之间不要有空格。

ibk_kyj3k4ffo4cvj7isbje2bqqn5frdxzv56c63aqq3hjwmbke46duq <(curl -Ls https://raw.githubusercontent.com/pingmike2/instabox-keepalive/main/keepalive.sh)

如果执行成功，终端会显示以下关键信息：

  • 续租 ok v1/keepalive （表示成功连接 API）
  • systemd 服务 instabox-keepalive 已装 （表示后台服务已运行）

说明：脚本默认会自动发现并保活该账号下的所有机器。以后新开的机器也会自动纳入保活范围。

第三步：日常查看状态与日志

在 VPS 上执行以下命令，查看当前机器的保活状态：

sh /root/instabox-keepalive/keepalive.sh --status

如果看到 state=running 和 autoSuspendedAt=（为空），说明一切正常。

如果需要实时监控日志，看它有没有在定时续租，执行：

journalctl -u instabox-keepalive -f

（按 Ctrl + C 退出日志查看）

附：卸载与手动操作

如果不想用了，或者需要卸载脚本：

sh /root/instabox-keepalive/keepalive.sh uninstall

如果需要手动立刻续租一次（不依赖自动任务）：

sh /root/instabox-keepalive/keepalive.sh --once

备用方案：纯网页保活（防 30 分钟闲置）

如果由于网络原因脚本失效，且你只需要防闲置，可以在你的 VPS 上添加定时任务去访问你 InstaBox 的网页地址：

*/10 * * * * curl -sS -m 10 "https://你的端口-你的机器ID.instabox.tech" > /dev/null
