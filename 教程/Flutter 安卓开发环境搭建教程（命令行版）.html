1环境总览与前置条件

本教程完成后，你的环境将是：

组件版本 / 路径
操作系统Windows 11
Flutter SDK3.47.5 stable，C:\flutter
Dart3.13.4（随 Flutter 自带）
Git2.45+
JDKMicrosoft OpenJDK 17，C:\Program Files\Microsoft\jdk-17.0.20.101-hotspot
Android 命令行工具C:\android\cmdline-tools\latest
Android SDKPlatform 36 + Build-tools 34.0.0，C:\android
ANDROID_HOMEC:\android
JAVA_HOMEC:\Program Files\Microsoft\jdk-17.0.20.101-hotspot

核心原则：全程使用 PowerShell，不打开 Android Studio。

💡 所有命令都可以直接点击右上角「复制」按钮复制到 PowerShell 中执行。

2安装 Git

Flutter 依赖 Git，先确认是否已安装：

PowerShell
git --version

如果显示版本号（如 git version 2.45.1.windows.1），跳过此步。

如果没有，去官网下载安装：

https://git-scm.com/download/win

安装时保持默认选项即可，它会自动把 Git 加入 PATH。

3安装 Flutter SDK

3.1 下载

官方稳定版下载地址：

https://docs.flutter.dev/get-started/install/windows

直接下载链接（3.47.5 stable）：

下载地址
https://storage.googleapis.com/flutter_infra_release/releases/stable/windows/flutter_windows_3.47.5-stable.zip

3.2 解压

解压到 C:\flutter，确保 C:\flutter\bin\flutter.bat 存在。

⚠️ 路径不要有中文和空格，不要放在 C:\Program Files\ 下。

3.3 加入 PATH

在 PowerShell 中执行：

PowerShell
[Environment]::SetEnvironmentVariable(
  "Path",
  [Environment]::GetEnvironmentVariable("Path", "User") + ";C:\flutter\bin",
  "User"
)

3.4 验证

关掉 PowerShell，重新打开，执行：

PowerShell
flutter --version

第一次运行会构建工具、下载依赖，需要等 1-3 分钟。成功后输出类似：

输出示例
Flutter 3.47.5 • channel stable
Framework • revision 6a19cca564
Engine • revision af7e796e16
Tools • Dart 3.13.4 • DevTools 2.60.0

4安装 JDK 17

Android 命令行工具需要 Java 环境。推荐 JDK 17。

4.1 用 winget 安装

PowerShell
winget install Microsoft.OpenJDK.17

等待下载（约 160 MB）和安装完成。

4.2 找到安装路径

PowerShell
Get-ChildItem "C:\Program Files\Microsoft" -Directory | Where-Object Name -like "jdk*"

输出类似 C:\Program Files\Microsoft\jdk-17.0.20.101-hotspot。

4.3 设置 JAVA_HOME

把上面得到的路径代入（注意版本号要完全一致）：

PowerShell
[Environment]::SetEnvironmentVariable("JAVA_HOME", "C:\Program Files\Microsoft\jdk-17.0.20.101-hotspot", "User")

[Environment]::SetEnvironmentVariable(
  "Path",
  [Environment]::GetEnvironmentVariable("Path", "User") + ";%JAVA_HOME%\bin",
  "User"
)

4.4 验证

重开 PowerShell，执行：

PowerShell
echo $env:JAVA_HOME
java -version

应输出 JDK 路径和 openjdk version "17.0.20.1"。

5安装 Android 命令行工具

5.1 下载

打开页面，找到「仅限命令行工具」区域：

https://developer.android.com/studio#command-line-tools-only

下载 Windows 版 zip（约 155 MB），文件名类似 commandlinetools-win-15859902_latest.zip。

5.2 解压并整理目录

解压到 C:\android\cmdline-tools，然后整理成如下结构：

目标结构
C:\android\
  └── cmdline-tools\
        └── latest\
              ├── bin\
              ├── lib\
              ├── NOTICE.txt
              └── source.properties

在 C:\android\cmdline-tools 下执行：

PowerShell
cd C:\android\cmdline-tools
mkdir latest
move bin latest
move lib latest
move NOTICE.txt latest
move source.properties latest
❌ latest 这一层不能省，否则 sdkmanager 会报 Could not determine SDK root。

5.3 设置环境变量

PowerShell
[Environment]::SetEnvironmentVariable("ANDROID_HOME", "C:\android", "User")

[Environment]::SetEnvironmentVariable(
  "Path",
  [Environment]::GetEnvironmentVariable("Path", "User") + ";C:\android\cmdline-tools\latest\bin;C:\android\platform-tools",
  "User"
)

5.4 验证

重开 PowerShell：

PowerShell
sdkmanager --version

能输出版本号（如 22.0）即成功。

6安装 Android SDK 组件与许可

6.1 安装必要组件

PowerShell
sdkmanager "platform-tools" "platforms;android-36" "build-tools;34.0.0"

中途问 Accept? (y/N) 时输入 y 回车。

💡 Flutter 3.47.5 要求 Android SDK Platform 36。Build-tools 用 34.0.0 即可，Flutter 提示里的 "BuildTools 28.0.3" 是固定文案，不用管。

6.2 接受所有许可

PowerShell
sdkmanager --licenses

一路按 y 回车，直到出现 All SDK package licenses accepted。

7验证环境

PowerShell
flutter doctor -v

期望结果：

项目状态
Flutter✅
Windows Version✅
Android toolchain✅
Chrome / Edge✅
Network resources✅
Visual Studio❌ 可忽略（不做 Windows 桌面应用）
💡 只要 Android toolchain 是 ✅，安卓开发环境就通了。Visual Studio 那个 ✗ 与安卓无关。

8创建并运行第一个 Flutter 项目

8.1 创建项目

PowerShell
cd C:\Users\Administrator
flutter create my_app
cd my_app

把 my_app 换成你想用的项目名（小写字母 + 下划线）。

8.2 查看可用设备

PowerShell
flutter devices

8.3 运行

连接安卓手机后：

PowerShell
flutter run

或者指定设备 ID：

PowerShell
flutter run -d <设备ID>

9连接安卓设备或模拟器

9.1 真机（推荐）

  1. 手机「设置」→「关于手机」→ 连点「版本号」7 次，开启开发者模式
  2. 「设置」→「开发者选项」→ 打开「USB 调试」
  3. 数据线连接电脑，手机弹出授权提示时点「允许」
  4. 验证：
PowerShell
adb devices

应显示一行设备序列号 + device。

9.2 模拟器（可选）

安装系统镜像和模拟器：

PowerShell
sdkmanager "emulator" "system-images;android-34;google_apis;x86_64"

创建 AVD：

PowerShell
avdmanager create avd -n pixel -k "system-images;android-34;google_apis;x86_64" -d pixel_6

启动模拟器：

PowerShell
emulator -avd pixel

10打包 APK

10.1 调试版 APK

PowerShell
flutter build apk --debug

输出路径：build\app\outputs\flutter-apk\app-debug.apk

10.2 发布版 APK

PowerShell
flutter build apk --release

输出路径：build\app\outputs\flutter-apk\app-release.apk

10.3 分架构打包（体积更小）

PowerShell
flutter build apk --split-per-abi

会生成 arm64-v8a、armeabi-v7a、x86_64 三个 APK，按手机架构选用。

⚠️ 发布版 APK 需要签名。首次打包会自动用 debug 签名，正式发布需配置 android/key.properties 和 keystore。

11常见问题

Q1: flutter 不是可识别的命令

PATH 没生效。检查：

PowerShell
$env:Path -split ';' | Select-String flutter
Test-Path C:\flutter\bin\flutter.bat

第一条应输出 C:\flutter\bin，第二条应输出 True。若 PATH 缺失，重新执行第 3.3 步并重开终端。

Q2: sdkmanager 报 JAVA_HOME is not set

JDK 没装或 JAVA_HOME 没设。回到第 4 步，确认：

PowerShell
echo $env:JAVA_HOME
java -version

Q3: sdkmanager 报 Could not determine SDK root

目录结构不对。确保是 C:\android\cmdline-tools\latest\bin\sdkmanager.bat，latest 这层必须在。

Q4: flutter doctor 提示 Android SDK 版本不够

补装对应 Platform：

PowerShell
sdkmanager "platforms;android-36"

Q5: 改了环境变量但没生效

环境变量只对新开的终端生效。关掉 PowerShell，重新打开再试。

Q6: Visual Studio 那个 ✗ 要不要管

不用。它只影响 Windows 桌面应用开发，与安卓无关。

Q7: 首次 flutter run 很慢

正常。首次会下载 Gradle、依赖包，可能几分钟到十几分钟。之后会快很多。
