1. 准备工作

在开始部署之前，请确保你具备以下条件：

  • 一台 VPS 服务器（Ubuntu / Debian 系统），拥有 root 或 sudo 权限。
  • 已安装 Docker 和 Docker Compose。如果未安装，请先执行：
    curl -fsSL https://get.docker.com | sh
  • 一个域名（可选，但推荐），并将 DNS 解析到你的 VPS 公网 IP。
  • 确保 VPS 防火墙 / 云安全组开放了 80 和 443 端口（用于 HTTP/HTTPS）。
💡 本文示例域名： bee.baoge.wang
实际操作时请替换为你自己的域名。如果没有域名，也可以直接用 IP 访问（仅 HTTP，不推荐生产使用）。

2. 一键部署 BeeCount

在 VPS 上执行以下命令，即可完成部署。所有数据会持久化到 ~/beecount/data 目录。

步骤 2.1 创建工作目录并启动容器

# 创建目录并进入 mkdir -p ~/beecount/data && cd ~/beecount # 运行 BeeCount 容器（端口映射 8869） docker run -d \ --name beecount \ --restart unless-stopped \ -p 8869:8080 \ -v ~/beecount/data:/data \ sunxiao0721/beecount-cloud:latest
📌 参数说明：
• -p 8869:8080 — 将容器内 8080 端口映射到宿主机 8869 端口。
• -v ~/beecount/data:/data — 数据持久化，所有账本数据都保存在此目录。
• --restart unless-stopped — 服务器重启后容器自动启动。

3. 获取管理员密码 & 登录

首次启动时，BeeCount 会自动生成一个随机的管理员密码。你需要通过以下命令查看：

# 查看初始管理员密码 docker exec beecount cat /data/.initial_admin_password

执行后会看到类似输出：

邮箱: owner@example.com 密码: FIDodUnwprkw1zUi

登录地址

  • 有域名（推荐）： https://你的域名（如 https://bee.baoge.wang）
  • 无域名（仅测试）： http://你的VPS公网IP:8869
⚠️ 安全提醒： 登录后请立即在「个人设置」中修改默认邮箱和密码，防止账号被盗。

4. 配置 HTTPS 域名访问（强烈推荐）

以下步骤使用 Let's Encrypt 免费证书，为你的域名启用 HTTPS。

步骤 4.1 申请 SSL 证书

# 停止 Nginx（如果运行中） systemctl stop nginx # 申请证书（替换 -d 后面的域名为你自己的） certbot certonly --standalone -d bee.baoge.wang \ --non-interactive --agree-tos --email admin@baoge123.de5.net

步骤 4.2 创建 Nginx 配置文件

# 创建配置文件（替换 bee.baoge.wang 为你的域名） cat > /etc/nginx/sites-available/beecount << 'EOF' server { listen 80; server_name bee.baoge.wang; return 301 https://$server_name$request_uri; } server { listen 443 ssl http2; server_name bee.baoge.wang; ssl_certificate /etc/letsencrypt/live/bee.baoge.wang/fullchain.pem; ssl_certificate_key /etc/letsencrypt/live/bee.baoge.wang/privkey.pem; location / { proxy_pass http://127.0.0.1:8869; proxy_http_version 1.1; proxy_set_header Host $host; proxy_set_header X-Real-IP $remote_addr; proxy_set_header X-Forwarded-For $proxy_add_x_forwarded_for; proxy_set_header X-Forwarded-Proto $scheme; proxy_set_header Upgrade $http_upgrade; proxy_set_header Connection "upgrade"; } } EOF

步骤 4.3 启用配置并重载 Nginx

ln -s /etc/nginx/sites-available/beecount /etc/nginx/sites-enabled/ nginx -t systemctl start nginx systemctl reload nginx
✅ 配置成功后： 浏览器访问 https://你的域名，即可通过 HTTPS 安全使用 BeeCount。

5. 清空所有数据（重置）

如果你想彻底清空所有记账数据，恢复到全新安装状态，请按以下步骤操作。

⚠️ 危险操作警告： 此操作将 永久删除 所有账本、交易、账户、分类等数据，且 不可恢复。执行前请确认已做好备份。

方法一：仅删除数据库文件（保留配置目录）

# 停止容器 docker stop beecount # 删除 SQLite 数据库文件 rm -f ~/beecount/data/*.db # 重新启动容器 docker start beecount

方法二：删除整个数据目录（更彻底）

# 停止容器 docker stop beecount # 删除整个数据目录 rm -rf ~/beecount/data # 重新创建目录并启动容器 mkdir -p ~/beecount/data docker start beecount
📌 说明： 无论使用哪种方法，容器重启后都会自动创建一个全新的空数据库，并生成新的随机管理员密码。

6. 获取重置后的新密码

清空数据并重启容器后，BeeCount 会像初次安装一样，生成一个新的随机管理员密码。执行以下命令查看：

# 查看新生成的初始密码 docker exec beecount cat /data/.initial_admin_password

输出示例：

邮箱: owner@example.com 密码: Xy9kLm2nPq7s

然后使用 邮箱 owner@example.com 和这个新密码登录即可。

💡 提示： 如果你在重置前修改过默认邮箱，重置后邮箱会恢复为 owner@example.com，密码也会重新随机生成。

7. 常用维护命令

以下是你日常维护 BeeCount 服务时可能用到的命令。

容器管理

# 查看容器运行状态 docker ps | grep beecount # 查看实时日志 docker logs -f beecount # 重启容器 docker restart beecount # 停止容器 docker stop beecount # 启动容器 docker start beecount # 更新到最新版本 docker pull sunxiao0721/beecount-cloud:latest docker stop beecount && docker rm beecount # 然后重新执行部署命令（参考第 2 节）

查看端口与访问

# 检查 BeeCount 端口是否正常监听 ss -tulnp | grep 8869 # 测试本地访问 curl -I http://127.0.0.1:8869 # 查看 Nginx 是否代理了 HTTPS ss -tulnp | grep -E ":80|:443"

数据备份与恢复

# 手动备份数据目录 tar -czf beecount-backup-$(date +%Y%m%d).tar.gz ~/beecount/data # 恢复备份（先停止容器） docker stop beecount rm -rf ~/beecount/data tar -xzf beecount-backup-20260101.tar.gz -C ~/beecount/ docker start beecount
📌 建议： 在 BeeCount Web 端「管理面板 → 备份系统」中配置自动加密备份到 S3 / WebDAV / Google Drive，更安全省心。
