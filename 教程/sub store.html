📦 Sub-Store 完全教程

Termux 本地部署后端 · PWA 网页版前端操作指南

本地生成 + 本地使用 · 数据完全掌握在自己手机中

① Termux 中部署 Sub-Store 后端

以下命令在 Termux 中依次执行：

# 1. 更新环境并安装必要工具
pkg update && pkg upgrade -y
pkg install nodejs-lts git -y

# 2. 安装 pnpm（官方推荐）
npm install -g pnpm

# 3. 克隆 Sub-Store 后端仓库
cd ~
git clone https://github.com/sub-store-org/Sub-Store.git
cd Sub-Store/backend

# 4. 安装依赖
pnpm i

# 5. 启动服务
pnpm start
✅ 启动成功会显示：Server is running on http://localhost:3000
📱 后端地址即为：http://127.0.0.1:3000（本机访问）或 http://手机IP:3000（局域网访问）
⚠️ 保持 Termux 运行状态。如需后台保活，可使用 tmux（见文末进阶）。
② Sub-Store PWA 网页版前端

前端地址（官方 PWA 网页版）：

🔗 https://sub-store.vercel.app/subs

这个网页的作用：

  • 它是一个纯前端界面（遥控器），本身不处理订阅数据
  • 需要连接到你刚才在 Termux 中启动的后端（电视机）才能工作
  • 所有订阅链接、节点信息都通过你自己的后端处理，不会上传到任何第三方
💡 你可以把该网页添加到手机桌面（PWA 特性），使用体验接近原生 App。
③ 在网页中配置后端地址

首次打开 https://sub-store.vercel.app/subs 时，会提示「后端连接配置」：

  1. 输入框中填写你的后端地址：http://127.0.0.1:3000
  2. 点击「确认」或「保存」
  3. 页面正常加载后即可使用
http://127.0.0.1:3000
⚠️ 如果提示「网络错误或后端异常」：
1. 检查 Termux 中的后端是否已启动（显示 Server is running）
2. 确认手机未开启 VPN 或代理拦截了本地回环
3. 尝试用 http://localhost:3000 替代 127.0.0.1
④ 添加单链接（单个订阅地址）

「单链接」就是你的机场订阅 URL、V2Ray 链接、Clash 链接等原始订阅地址。

  1. 打开 Sub-Store 网页后，点击底部菜单栏的 「订阅」 或 「Subscriptions」
  2. 点击右下角的 「+」 按钮（添加订阅）
  3. 填写以下信息：
    • 名称：自定义，例如「我的机场」
    • 链接：粘贴你的原始订阅 URL
    • 格式：选择「自动」（程序会自动识别）
  4. 点击 「保存」 或 「确定」
  5. 系统会自动拉取并解析该订阅的节点列表
📌 添加成功后，你可以在「订阅」页面看到该条记录，点击可查看节点详情。
⑤ 添加集合（组合多个订阅）

「集合」也叫「组合订阅」，可以将多个单链接合并、筛选、重命名后，生成一个新的订阅链接给代理软件使用。

基础操作步骤：

  1. 点击底部菜单栏的 「组合」 或 「Combinations」
  2. 点击右下角的 「+」 按钮
  3. 填写组合信息：
    • 名称：例如「日常组合」
    • 选择订阅：勾选你之前添加的一个或多个单链接
  4. （可选）点击「添加规则」进行高级配置：
    • 节点筛选：只保留某些地区或关键词的节点
    • 节点重命名：批量添加前缀/后缀
    • 策略组调整：针对 Clash/Surge 的规则配置
  5. 点击 「保存」

导出订阅链接给代理软件：

  1. 在「组合」页面，点击你刚创建的组合条目
  2. 选择 「导出」 或点击分享/复制图标
  3. 根据你的代理软件选择格式：
    • Clash / Clash Meta (Mihomo) → 选 Clash
    • Sing-box → 选 sing-box
    • Surge → 选 Surge
    • Loon / Quantumult X → 对应选项
  4. 点击「复制链接」，将链接粘贴到你的代理 App 的订阅地址中
🔁 进阶技巧：集合的集合 — 你可以先创建组合 A（包含订阅1+订阅2），再创建组合 B，在「选择订阅」时直接勾选组合 A，这样 B 就包含了 A 里的所有节点。

🔧 进阶 · Termux 后台保活

使用 tmux 让后端在后台持续运行：

pkg install tmux -y
tmux new -s substore
# 进入会话后执行 cd ~/Sub-Store/backend && pnpm start
# 按 Ctrl+B 然后按 D 脱离会话（服务继续运行）
# 重新进入：tmux attach -t substore
# 查看所有会话：tmux ls
🔋 Android 系统可能会杀后台进程，请在系统设置中将 Termux 加入「电池优化白名单」并锁定任务卡片。
❓ 常见问题排查

Q1: 网页提示「网络错误或后端异常」怎么办？

A: ①确认 Termux 中后端已启动（显示 Server running）；②确认填写的是 http://127.0.0.1:3000 而非 https；③关闭手机 VPN 或代理软件后再试。

Q2: pnpm i 安装失败或速度慢？

A: 切换国内镜像源：pnpm config set registry https://registry.npmmirror.com

Q3: 添加订阅后看不到节点？

A: 检查原始订阅链接是否有效（可以在浏览器中打开看是否有返回内容）；确认订阅格式选择正确。

Q4: 代理软件导入组合链接后无法更新？

A: 先用手机浏览器访问该组合链接，看能否正常返回配置内容；检查代理软件是否填写了正确的订阅地址。

Q5: 如何更新 Sub-Store 到最新版？

A: cd ~/Sub-Store/backend && git pull && pnpm i，然后重启服务。

Q6：修改启动配置，让它监听同一WIFI下所有网络接口

A: # 1. 停止当前运行的服务 (Ctrl+C) # 2. 设置环境变量并重新启动：SUB_STORE_BACKEND_HOST="0.0.0.0" pnpm start

📌 完整工作流程回顾
  1. Termux 中启动后端：cd ~/Sub-Store/backend && pnpm start
  2. 打开前端网页：https://sub-store.vercel.app/subs
  3. 配置后端地址：填入 http://127.0.0.1:3000
  4. 添加单链接：订阅页面 → + → 输入名称和订阅 URL
  5. 创建集合：组合页面 → + → 勾选订阅 → 保存
  6. 导出并使用：点击组合 → 选择格式 → 复制链接 → 粘贴到代理软件
🎯 一次配置完成后，日常使用只需要：保持 Termux 后端运行 → 打开网页前端 → 更新/添加订阅即可。
