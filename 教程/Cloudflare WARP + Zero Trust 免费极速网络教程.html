第一步：注册Cloudflare账号并开通Zero Trust

  • 打开 Cloudflare 官网 (cloudflare.com) ，点击右上角注册账号（支持邮箱、Google、Apple ID等直接登录）。
  • 登录后，在左侧菜单栏找到并点击 Zero Trust。
  • 首次进入会让你创建一个团队名称(Team Name) 。随便起一个（例如 aitekeji2026），请务必记住这个名字，后面要用！
  • 选择套餐时，直接选择 $0 的免费套餐（Free Plan），支持50个设备，绝对够用。如果提示绑定支付方式，直接点击“取消并退出”即可，不影响使用。
小贴士： 免费版包含Zero Trust核心功能 + WARP 设备注册，适合个人和中小团队，50设备完全够折腾。

第二步：配置连接模式（关键优化）

  • 再次进入 Zero Trust后台，在左侧找到 Settings（设置） -> WARP Client（WARP客户端）。
  • 找到 Profile Settings（配置文件设置），确保代理模式选择为 Gateway with WARP（同时代理流量和DNS，最稳定）。
  • 路由配置（Split Tunnels） 选择默认的 Exclude（排除） 模式即可。
# 配置路径参考：
Zero Trust → Settings → WARP Client → 编辑Profile →
Service mode: Gateway with WARP ✅
Split Tunnels: Exclude IPs and domains（默认多数流量走WARP，更畅快）

第三步：下载并登录WARP客户端（团队模式）

  • 在Zero Trust后台找到下载链接，或者直接去 官网下载对应系统（Windows / macOS / iOS / Android / Linux）。
  • 安装完成后，打开状态栏的WARP图标 （先不要点击连接！）。
  • 点击右下角的齿轮（设置）图标 → 偏好设置(Preferences) → 账户(Account)。
  • 点击 “登录到Cloudflare Zero Trust” 。
  • 在弹出的网页中，输入你第一步设置的团队名称(Team Name) ，例如 aitekeji2026。
  • 输入你的注册邮箱，查收6位数验证码并填入。页面提示成功后，回到客户端。
  • 打开WARP客户端主开关，点击连接 ⚡。
登录验证关键点： 必须选择“Cloudflare Zero Trust”而不是普通WARP模式！输入团队名称后，会跳转邮箱验证码，成功绑定后界面会显示“您的团队正在保护此设备”。
