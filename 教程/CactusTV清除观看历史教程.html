🧹 清除观看历史 Cactus TV · D1 数据库

⚠️ 操作前请务必注意：
  • 此操作将永久删除所有观看历史和播放进度，不可恢复。
  • 此部署为私人影院，所有用户共用一份数据，清空后所有人记录都会消失。
  • 建议先执行 SELECT 语句确认数据量，再执行 DELETE。

1. 进入 D1 数据库控制台

1 登录 Cloudflare Dashboard，进入 Workers & Pages。
2 在左侧菜单或项目列表中找到你的 D1 数据库（例如 cactus-tv-db），点击进入。
3 点击顶部 "SQL Console" 选项卡，打开 SQL 查询编辑器。
💡 提示： 如果找不到 D1，可以在 Pages 项目绑定的资源列表中找到数据库链接。

2. 查看当前历史记录数量

📊 在 SQL Console 中执行以下命令，确认要删除的数据量： 
SELECT COUNT(*) FROM watch_history;复制
✅ 如果返回数字大于 0，说明有历史记录可以清除。

3. 执行删除操作

🗑️ 确认无误后，执行以下 SQL 清空全部观看历史： 
DELETE FROM watch_history;复制
🚨 再次确认： 此操作将删除 watch_history 表中的所有记录，且无法撤销。请确保你真的需要这样做。

4. 验证清除结果

✅ 删除完成后，再次执行查询，确认记录已清空： 
SELECT COUNT(*) FROM watch_history;复制
🎯 如果返回结果为 0，说明历史记录已全部清除。

📌 其他相关操作

清空播放进度（如果单独存储）：
DELETE FROM watch_progress;复制
清空收藏片单：
DELETE FROM favorites;复制
💡 如果只想删除某一条记录，可以用 DELETE FROM watch_history WHERE id = 具体ID;，先 SELECT * FROM watch_history; 查看每条记录的 ID。
