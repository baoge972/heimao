📊 青龙面板：Pi币与全球行情早报

本教程将指导你在青龙面板中创建一个 Python 脚本，每天定时抓取 Pi 币、比特币、以太坊以及实时汇率和黄金价格，并排版推送到 Telegram。

第一步：安装 Python 依赖

  1. 进入青龙面板左侧菜单的 “依赖管理”。
  2. 点击 “创建依赖”。
  3. 依赖类型：选择 python3。
  4. 自动拆分：选择 否。
  5. 名称：填入 requests。
  6. 点击确定并等待安装完成。

第二步：新建脚本文件

  1. 进入 “脚本管理”。
  2. 在右侧空白处右键，选择 “新建文件”。
  3. 文件名填入：market_daily.py（注意必须是 .py 后缀）。
  4. 双击打开该文件，将下方代码完整复制并粘贴进去，点击 “保存”。
import requests
import sys
from datetime import datetime

# ================= 配置区 =================
CRYPTO_IDS = "pi-network,bitcoin,ethereum"
# =========================================

def get_crypto_prices():
    url = f"https://api.coingecko.com/api/v3/simple/price?ids={CRYPTO_IDS}&vs_currencies=usd,cny&include_24hr_change=true"
    headers = {
        "User-Agent": "Mozilla/5.0 (Windows NT 10.0; Win64; x64) AppleWebKit/537.36 (KHTML, like Gecko) Chrome/120.0.0.0 Safari/537.36"
    }
    try:
        response = requests.get(url, headers=headers, timeout=10)
        response.raise_for_status()
        return response.json()
    except Exception:
        return None

def get_gold_price():
    # 获取 COMEX 黄金期货价格 (美元/盎司)
    url = "https://query1.finance.yahoo.com/v8/finance/chart/GC=F?interval=1d"
    headers = {"User-Agent": "Mozilla/5.0"}
    try:
        response = requests.get(url, headers=headers, timeout=10)
        data = response.json()
        return data['chart']['result'][0]['meta']['regularMarketPrice']
    except Exception:
        return None

def get_exchange_rate():
    # 获取实时美元兑人民币汇率
    url = "https://query1.finance.yahoo.com/v8/finance/chart/CNY=X?interval=1d"
    headers = {"User-Agent": "Mozilla/5.0"}
    try:
        response = requests.get(url, headers=headers, timeout=10)
        data = response.json()
        return data['chart']['result'][0]['meta']['regularMarketPrice']
    except Exception:
        return 7.25 # 兜底汇率

def main():
    time_now = datetime.now().strftime('%Y-%m-%d %H:%M:%S')
    crypto_data = get_crypto_prices()
    gold_usd = get_gold_price()
    usd_cny = get_exchange_rate()
    
    msg_lines = [
        f"☀️ **每日行情早报** ☀️",
        f"⏰ {time_now}",
        f"💱 美元/人民币: **{usd_cny:.4f}**",
        "━━━━━━━━━━━━━━"
    ]

    # 1. 加密货币区
    if crypto_data:
        if "pi-network" in crypto_data:
            pi = crypto_data["pi-network"]
            pi_change = pi.get('usd_24h_change', 0)
            pi_icon = "📈" if pi_change >= 0 else "📉"
            msg_lines.append(f"🪙 **Pi Network**  {pi_icon} {pi_change:+.2f}%")
            msg_lines.append(f"  💵 ${pi['usd']:.4f}  |  🇨🇳 ￥{pi['cny']:.4f}\n")
        
        if "bitcoin" in crypto_data:
            btc = crypto_data["bitcoin"]
            btc_change = btc.get('usd_24h_change', 0)
            btc_icon = "📈" if btc_change >= 0 else "📉"
            msg_lines.append(f"🟠 **比特币 (BTC)**  {btc_icon} {btc_change:+.2f}%")
            msg_lines.append(f"  💵 ${btc['usd']:,.2f}  |  🇨🇳 ￥{btc['cny']:,.2f}\n")
            
        if "ethereum" in crypto_data:
            eth = crypto_data["ethereum"]
            eth_change = eth.get('usd_24h_change', 0)
            eth_icon = "📈" if eth_change >= 0 else "📉"
            msg_lines.append(f"🔷 **以太坊 (ETH)**  {eth_icon} {eth_change:+.2f}%")
            msg_lines.append(f"  💵 ${eth['usd']:,.2f}  |  🇨🇳 ￥{eth['cny']:,.2f}\n")
    else:
        msg_lines.append("❌ 加密货币数据获取失败\n")

    msg_lines.append("━━━━━━━━━━━━━━")

    # 2. 黄金区
    if gold_usd:
        gold_cny_gram = (gold_usd * usd_cny) / 31.1035
        msg_lines.append(f"🥇 **黄金 (国际现货)**")
        msg_lines.append(f"  💵 ${gold_usd:,.2f} / 盎司")
        msg_lines.append(f"  🇨🇳 约 ￥{gold_cny_gram:.2f} / 克")
    else:
        msg_lines.append("❌ 黄金数据获取失败")

    # 3. 组装成最终消息并推送
    final_msg = "\n".join(msg_lines)
    print(f"## 开始推送\n{final_msg}\n## 推送结束")

if __name__ == "__main__":
    main()

第三步：创建定时任务

  1. 进入左侧菜单的 “定时任务”。
  2. 点击 “创建任务”。
  3. 名称：填入 每日行情早报。
  4. 命令/脚本：填入 task market_daily.py （注意这里的文件名必须与第二步建的文件名一致）。
  5. 定时规则：填入 0 7 * * * （代表每天早上 7:00 执行）。
  6. 点击确定保存。
💡 提示： 青龙面板默认只有“定时自动触发”才会推送 Telegram 消息。如果你现在点击“手动运行”，只能看到日志，手机不会响。如果想验证排版，请等第二天早上 7 点，或者在定时规则里临时改成 1 分钟后触发。
