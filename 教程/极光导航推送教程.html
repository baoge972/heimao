1日常推送（三步搞定）

在项目根目录打开终端（PowerShell），依次执行：

# 第一步：添加所有改动 git add -A # 第二步：提交（写清楚改了什么） git commit -m "描述你的修改内容" # 第三步：推送到 GitHub git push
提示：推送后 CF Pages 会自动检测到变更，触发构建和部署，通常 2-3 分钟完成。

2只推送指定文件

如果只想推送某些文件，不用 git add -A：

# 添加指定文件 git add app/page.tsx functions/api/market.ts # 提交 + 推送 git commit -m "修复行情卡片" git push

3查看当前状态

# 查看哪些文件被修改了 git status --short # 查看具体改了什么 git diff # 查看提交历史（最近5条） git log --oneline -5
状态标记含义
M已修改 文件内容变了
A新增 新文件已暂存
D删除 文件被删除
??未跟踪的新文件（还没 git add）

4撤销操作

# 撤销单个文件的修改（还没 add） git checkout -- 文件路径 # 撤销 git add（文件回到未暂存状态） git reset HEAD 文件路径 # 撤销上一次 commit（改动保留在工作区） git reset --soft HEAD~1 # 撤销上一次 commit（改动全部丢弃⚠️） git reset --hard HEAD~1
⚠️ git reset --hard 会丢弃所有未提交的改动，不可恢复，慎用！

5D1 数据库操作

需要执行 SQL 时，在 Cloudflare 面板操作：

  • 登录 Cloudflare Dashboard
  • 进入 Workers & Pages → D1
  • 点击你的数据库 → Console 标签
  • 粘贴 SQL 语句，点击 Run 执行
注意：D1 Console 不支持 -- 开头的注释行，粘贴前需删除注释。
大段 SQL 建议拆分成多个小段依次执行。

6图标文件管理

图标文件在 public/uploads/icons/ 目录，已加入 .gitignore，不会推送到仓库。

  • 上传的新图标自动以 base64 格式存入 D1 数据库
  • 自动抓取的图标使用 Google Favicon 外部链接
  • 如需手动添加图标文件，放入 public/uploads/icons/ 并推送
如需将图标纳入 Git：编辑 .gitignore 删除 /public/uploads/icons 那行，然后推送即可。
