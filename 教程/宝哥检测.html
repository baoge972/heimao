🔌 Pi Node 端口检测工具 · 部署教程

📌 功能特性

✅ 检测 31400-31409 全部端口
📊 显示真实区块高度
⏱️ 计算区块延迟时间
🔄 IP 历史记录（下拉列表）
🖼️ Pi Network Logo 图标
📱 移动端适配

📌 适用环境

  • 操作系统：Ubuntu 22.04 / 24.04
  • 已安装 Nginx

🚀 分步部署

💡 逐条复制执行，每步独立。
1 安装 PHP
apt update apt install -y php-fpm php-curl
2 创建站点目录
mkdir -p /var/www/port-checker
3 创建 index.php

4 设置权限
chown -R www-data:www-data /var/www/port-checker systemctl restart php8.3-fpm
5 配置 Nginx
cat > /etc/nginx/conf.d/port-checker.conf << 'EOF' server { listen 8088; server_name _; root /var/www/port-checker; index index.php; location / { try_files $uri $uri/ /index.php?$query_string; } location ~ \.php$ { include snippets/fastcgi-php.conf; fastcgi_pass unix:/run/php/php-fpm.sock; } } EOF
6 重载 Nginx
nginx -t && systemctl reload nginx
7 获取服务器 IP
curl -s ifconfig.me

✅ 访问地址

http://服务器IP:8088/

📌 配置域名（可选）

# 将 your-domain.com 替换为您的域名 cat > /etc/nginx/conf.d/port-checker.conf << 'EOF' server { listen 80; server_name your-domain.com; root /var/www/port-checker; index index.php; location / { try_files $uri $uri/ /index.php?$query_string; } location ~ \.php$ { include snippets/fastcgi-php.conf; fastcgi_pass unix:/run/php/php-fpm.sock; } } EOF nginx -t && systemctl reload nginx
⚠️ 部署前请确认服务器已放行 8088 端口（或 80/443 端口配置域名时）。
