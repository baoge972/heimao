🔌 Pi Node 端口检测工具 · 部署教程

📌 功能特性

✅ 检测 31400-31409 全部端口
📊 显示真实区块高度（从 Horizon API 获取）
⏱️ 计算区块延迟时间
📈 判断延迟趋势（增加/减少）
🔄 检测历史 IP 自动保存（下拉列表）
🖼️ Pi Network Logo 图标
⚡ 真实数据，无虚假占位
📱 移动端适配

📌 适用环境

  • 操作系统：Ubuntu 22.04 / 24.04
  • 已安装 Nginx
  • 已安装 PHP 8.3+

🚀 一键部署

💡 复制下面整段命令，粘贴到服务器终端执行即可完成全部部署。

📌 使用说明

1 复制上面 "一键部署" 区域的整段代码
2 粘贴到服务器终端，按 Enter 执行
3 等待部署完成后，访问 http://服务器IP:8088/
✅ 部署完成后即可使用，输入任意 IP 检测节点状态。

📊 检测结果说明

状态含义
✅ 端口打开 / 节点正常节点运行正常，区块延迟显示在下方
⏳ 端口打开 / 节点正常 / 区块同步中节点正在追赶最新区块
❌ 端口异常 / 节点状态异常 / 区块未知IP 不是 Pi 节点或无法访问

📌 配置域名（可选）

# 替换 your-domain.com 为您的域名 cat > /etc/nginx/conf.d/port-checker.conf << 'EOF' server { listen 80; server_name your-domain.com; root /var/www/port-checker; index index.php; location / { try_files $uri $uri/ /index.php?$query_string; } location ~ \.php$ { include snippets/fastcgi-php.conf; fastcgi_pass unix:/run/php/php-fpm.sock; } } EOF nginx -t && systemctl reload nginx
