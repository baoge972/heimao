接下来，我把完整的注册、安装和配置流程整理成一篇详细教程，照着步骤操作即可。

第一步：注册 Cloudflare 账号

  • 打开 Cloudflare 官网 (cloudflare.com)，可以把页面语言切换成中文，点击“免费开始使用”。
  • 注册方式很灵活，可以使用 Google 账号、Apple 账号快速登录，也可以通过邮箱注册。
  • 登录成功后，在左侧菜单找到 Zero Trust 入口并点击进入。如果是第一次使用，会看到欢迎界面，点击“开始使用”。

第二步：创建团队名称 & 选择免费套餐

  • 创建一个团队名称 (Team Name)。这个名称会生成一个唯一的 Zero Trust 域名标识，后续登录客户端时会用到。名称可以自定义，如果被占用就换一个即可。
  • 创建完成后，选择免费套餐（0 元方案即可）。免费版支持最多 50 个席位，也就是 50 个设备或子账号，日常个人使用完全足够。
  • 在套餐页面，如果不想添加付款方式，可以直接取消并退出，功能依然可以正常使用。
小贴士： 免费套餐长期有效，支持50个设备，无需担心流量或期限问题。

第三步：下载 WARP 客户端

  • 重新进入 Zero Trust，在左下角找到“设置”或“集成”选项，进入“服务提供商”相关页面，找到 WARP 客户端注册入口。点击“添加设备”，系统就会提示你下载 WARP 客户端。
  • 目前客户端支持 Windows、macOS、Linux、iOS、Android 等主流系统。选择对应系统下载稳定版即可。
  • Windows 版本安装包大约 130MB，支持 Windows 10、Windows 11 以及 Windows 365。

第四步：配置注册策略与连接模式

  • 安装完成后，回到浏览器页面继续下一步配置。系统会引导你设置注册策略。默认会自动允许当前登录邮箱注册设备，也可以自定义策略名称。
  • 接下来选择服务模式时，建议选择 “流量 + DNS 双重代理模式”。这种模式更稳定，相当于双通道运行：DNS 出问题可以走流量代理，流量异常可以通过 DNS 进行切换。
  • 在默认路由配置阶段，选择 “排除模式”，即默认将所有流量发送到 Cloudflare，仅对例外流量进行排除。
  • 特别注意事项： 这一步一定要关闭电脑上其他 VPN 或代理工具，否则后续无法正常连接。
⚠️ 关键操作： 确保电脑上现有的其他 VPN、代理软件（如 Clash、V2Ray、Shadowsocks 等）已完全退出，否则 WARP 无法正常建立隧道。

第五步：登录 Zero Trust 并连接

  • 全部设置完成后，系统会提示你在客户端登录 Zero Trust。
  • 打开右下角任务栏中的 WARP 图标，进入“设置”→“首选项”→“账户”，选择“使用 Cloudflare Zero Trust 登录”。
  • 这时需要输入你刚才创建的团队名称（例如 youname）。输入后，系统会向注册邮箱发送验证码，填写验证码即可完成登录。
  • 登录成功后，点击“连接”。几秒钟内就会建立隧道，状态显示“已连接，您的网络已受保护”。
登录验证提示： 如果收不到验证码，请检查邮箱垃圾箱，或稍等一分钟重试。团队名称务必与 Zero Trust 后台完全一致。
