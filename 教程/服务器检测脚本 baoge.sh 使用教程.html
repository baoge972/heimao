📊 服务器检测脚本 baoge.sh

一个轻量级服务器检测脚本，一键生成包含 CPU、内存、硬盘、端口、Docker、服务、防火墙等 15 项信息的全面报告。

📋 检测内容

编号检测项说明
1系统信息操作系统版本、内核、运行时间
2CPU 信息型号、核心数、架构
3内存信息总内存、已用、可用、Swap
4硬盘信息分区和使用率
5端口占用31400-31409 及其他常用端口
6Docker 容器所有容器的状态和端口映射
7运行服务systemd 管理的服务列表
8Nginx 站点已配置的站点和域名
9防火墙状态UFW/iptables 状态
10公网 IP当前服务器的公网 IP
11代理环境HTTP/HTTPS 代理变量
12FRP 状态FRP 服务运行状态
13Pi Node 检查检测 31401 端口是否响应
14资源占用 TOPCPU 和内存占用最高的进程
15快速总结核心指标 + 建议

🚀 一键执行

复制下面整段代码，粘贴到终端，按回车即可自动完成所有操作：

# ============================================== # 一键创建 baoge.sh 并执行 # ============================================== cat > baoge.sh << 'EOF' #!/bin/bash # ============================================ # 服务器一键检测脚本 # 用法: ./baoge.sh # ============================================ RED='\033[0;31m' GREEN='\033[0;32m' YELLOW='\033[1;33m' BLUE='\033[0;34m' NC='\033[0m' echo "" echo "==========================================" echo " 服务器全面检测报告" echo " 生成时间: $(date)" echo "==========================================" echo "" echo -e "${BLUE}【1】系统信息${NC}" echo "----------------------------------------" cat /etc/os-release 2>/dev/null | grep -E "PRETTY_NAME|VERSION_ID" | sed 's/^/ /' uname -a | sed 's/^/ 内核: /' echo " 运行时间: $(uptime -p)" echo " 当前用户: $(whoami)" echo "" echo -e "${BLUE}【2】CPU 信息${NC}" echo "----------------------------------------" echo " 型号: $(cat /proc/cpuinfo | grep "model name" | head -1 | cut -d: -f2 | xargs)" echo " 核心数: $(nproc)" echo " 架构: $(uname -m)" echo "" echo -e "${BLUE}【3】内存信息${NC}" echo "----------------------------------------" free -h | grep -E "Mem|Swap" | sed 's/^/ /' echo "" echo -e "${BLUE}【4】硬盘信息${NC}" echo "----------------------------------------" df -h | grep -E "Filesystem|/dev/vd|/dev/sd" | sed 's/^/ /' echo "" echo -e "${BLUE}【5】端口占用 (31400-31409 & 常用端口)${NC}" echo "----------------------------------------" echo " 31401-31403 端口:" ss -tlnp 2>/dev/null | grep -E "3140[1-3]" | sed 's/^/ /' if [ -z "$(ss -tlnp 2>/dev/null | grep -E "3140[1-3]")" ]; then echo " (无监听)" fi echo "" echo " 其他重要端口:" ss -tlnp 2>/dev/null | grep -E ":80 |:443 |:22 |:3000 |:8080 |:7000 " | sed 's/^/ /' echo "" echo -e "${BLUE}【6】Docker 容器${NC}" echo "----------------------------------------" if command -v docker &> /dev/null; then docker ps -a --format "table {{.Names}}\t{{.Status}}\t{{.Ports}}" 2>/dev/null | sed 's/^/ /' else echo " Docker 未安装" fi echo "" echo -e "${BLUE}【7】运行中的系统服务${NC}" echo "----------------------------------------" systemctl list-units --type=service --state=running --no-pager 2>/dev/null | head -25 | sed 's/^/ /' echo " ..." echo "" echo -e "${BLUE}【8】Nginx 站点配置${NC}" echo "----------------------------------------" if [ -d "/etc/nginx/sites-enabled" ]; then ls -la /etc/nginx/sites-enabled/ 2>/dev/null | grep -v "total" | sed 's/^/ /' echo " 站点域名:" grep -r "server_name" /etc/nginx/sites-enabled/ 2>/dev/null | grep -v "#" | sed 's/^/ /' else echo " Nginx 未安装或未配置" fi echo "" echo -e "${BLUE}【9】防火墙状态${NC}" echo "----------------------------------------" if command -v ufw &> /dev/null; then echo " UFW: $(ufw status 2>/dev/null | head -1)" fi if command -v iptables &> /dev/null; then echo " iptables 规则数: $(iptables -L -n 2>/dev/null | wc -l)" fi echo "" echo -e "${BLUE}【10】公网 IP${NC}" echo "----------------------------------------" PUBLIC_IP=$(curl -s --max-time 3 ifconfig.me 2>/dev/null) if [ -n "$PUBLIC_IP" ]; then echo " 公网 IP: $PUBLIC_IP" else echo " 公网 IP: 获取失败" fi echo "" echo -e "${BLUE}【11】代理环境变量${NC}" echo "----------------------------------------" env | grep -i proxy | sed 's/^/ /' if [ -z "$(env | grep -i proxy)" ]; then echo " (无代理设置)" fi echo "" echo -e "${BLUE}【12】FRP 服务状态${NC}" echo "----------------------------------------" if systemctl is-active --quiet frps 2>/dev/null; then echo " FRP 服务: 运行中" ps aux | grep frps | grep -v grep | sed 's/^/ /' else echo " FRP 服务: 未运行或未安装" fi echo "" echo -e "${BLUE}【13】Pi Node 相关检查${NC}" echo "----------------------------------------" if [ -n "$PUBLIC_IP" ]; then echo " 检测 $PUBLIC_IP:31401/health ..." CURL_RESULT=$(curl -s --max-time 2 http://$PUBLIC_IP:31401/health 2>/dev/null) if [ -n "$CURL_RESULT" ]; then echo " ✅ 31401 端口响应: $CURL_RESULT" else echo " ❌ 31401 端口无响应" fi else echo " (跳过，公网 IP 获取失败)" fi echo "" echo -e "${BLUE}【14】资源占用 TOP 10${NC}" echo "----------------------------------------" echo " CPU 占用 Top 5:" ps aux --sort=-%cpu | head -6 | sed 's/^/ /' echo "" echo " 内存占用 Top 5:" ps aux --sort=-%mem | head -6 | sed 's/^/ /' echo "" echo -e "${BLUE}【15】快速总结${NC}" echo "----------------------------------------" MEM_TOTAL=$(free -m | grep Mem | awk '{print $2}') MEM_USED=$(free -m | grep Mem | awk '{print $3}') MEM_FREE=$(free -m | grep Mem | awk '{print $7}') DISK_USED=$(df -h / | tail -1 | awk '{print $5}') CPU_CORES=$(nproc) echo " CPU 核心: $CPU_CORES" echo " 内存总量: ${MEM_TOTAL}MiB" echo " 内存已用: ${MEM_USED}MiB" echo " 内存可用: ${MEM_FREE}MiB" echo " 硬盘使用: $DISK_USED" if [ $MEM_TOTAL -lt 1024 ]; then echo -e " ${YELLOW}⚠️ 警告: 内存偏小 (${MEM_TOTAL}MiB)，部署新服务请选择轻量级方案${NC}" else echo -e " ${GREEN}✅ 内存充足${NC}" fi echo "" echo "==========================================" echo " 检测完成！" echo "==========================================" echo "" EOF # 添加执行权限 chmod +x baoge.sh # 执行脚本 ./baoge.sh

📌 后续使用

以后想再次检测服务器状态，只需要在终端执行：

./baoge.sh

📌 只创建脚本（不自动运行）

如果你只想创建脚本文件，稍后手动运行，可以执行：

cat > baoge.sh << 'EOF' # 脚本内容（见上方完整版） EOF chmod +x baoge.sh

然后需要时执行：

./baoge.sh

📌 保存报告到文件

如果想将检测结果保存为文件，方便查看和分享：

./baoge.sh > server_report_$(date +%Y%m%d_%H%M%S).txt

⚠️ 常见问题

Q: 提示 "Permission denied"？
执行 chmod +x baoge.sh 添加执行权限即可。
Q: 脚本执行到一半卡住了？
按 Ctrl + C 终止，检查网络连接后重新执行。
Q: 想修改脚本内容？
用 vi baoge.sh 或 nano baoge.sh 编辑即可。
⚠️ 注意：
脚本需要在 root 用户 或具有 sudo 权限 的用户下执行，否则部分信息（如端口、服务状态）可能无法完整显示。
