1安装 Git

PowerShell
git --version

没有输出版本号就去 git-scm.com 下载安装，默认选项即可。

2安装 Flutter SDK

下载稳定版 zip：

下载地址
https://storage.googleapis.com/flutter_infra_release/releases/stable/windows/flutter_windows_3.47.5-stable.zip

解压到 C:\flutter，确保 C:\flutter\bin\flutter.bat 存在。

加入 PATH：

PowerShell
[Environment]::SetEnvironmentVariable(
  "Path",
  [Environment]::GetEnvironmentVariable("Path", "User") + ";C:\flutter\bin",
  "User"
)
⚠️ 改 PATH 后必须关掉 PowerShell 重新打开，否则不生效。

验证：

PowerShell
flutter --version

应输出 Flutter 3.47.5 • channel stable。第一次跑会构建工具、下载依赖，等几分钟。

3安装 JDK 17

PowerShell
winget install Microsoft.OpenJDK.17

装完找路径：

PowerShell
Get-ChildItem "C:\Program Files\Microsoft" -Directory | Where-Object Name -like "jdk*"

设 JAVA_HOME（把路径换成实际输出）：

PowerShell
[Environment]::SetEnvironmentVariable("JAVA_HOME", "C:\Program Files\Microsoft\jdk-17.0.20.101-hotspot", "User")

[Environment]::SetEnvironmentVariable(
  "Path",
  [Environment]::GetEnvironmentVariable("Path", "User") + ";%JAVA_HOME%\bin",
  "User"
)

重开 PowerShell，验证：

PowerShell
echo $env:JAVA_HOME
java -version

下载 Windows 版 command line tools：

https://developer.android.com/studio#command-line-tools-only

解压到 C:\android\cmdline-tools，然后整理成：

目标结构

第三部分：构建与安装

改代码后，别急着 clean

⚠️ flutter clean 会清掉所有编译缓存（包括 libmpv 原生库），下次构建要重新下载，非常慢。日常改 Dart 代码，直接构建即可。

Debug 版（调试用）

PowerShell
cd C:\Users\Administrator\baoge_music
flutter build apk --debug

产物：build\app\outputs\flutter-apk\app-debug.apk（约 200 MB）

Release 版（正式用，推荐）

PowerShell
flutter build apk --release --split-per-abi

产物：

文件大小用途
app-arm64-v8a-release.apk约 24 MB现代手机、车机
app-armeabi-v7a-release.apk约 21 MB老设备
app-x86_64-release.apk约 26 MB模拟器

安装到手机

PowerShell
adb devices
adb install -r build\app\outputs\flutter-apk\app-arm64-v8a-release.apk
💡 -r 是覆盖安装，保留数据（收藏、改名、设置）。别用 adb uninstall，那会清数据。

手机连不上 adb？

  1. 手机开启开发者模式 + USB 调试
  2. USB 模式改成「传输文件」
  3. 弹「允许 USB 调试」勾「始终允许」
  4. 换数据线、换 USB 口
PowerShell
adb kill-server
adb start-server
adb devices

还不行就手动拷 apk 到手机，用文件管理器点开安装。

改 App 名称和图标

名称：AndroidManifest.xml 里 android:label="宝哥音乐"

图标：把 1024×1024 PNG 放到 assets/icon.png，然后：

PowerShell
dart run flutter_launcher_icons

第四部分：功能模块说明

4.1 本地音乐扫描

流程：

  1. App 申请 READ_MEDIA_AUDIO 权限
  2. 调 MainActivity.kt 的 querySongs
  3. Kotlin 查 MediaStore，返回 id、标题、歌手、时长、folder（文件夹）、content:// URI
  4. Dart 侧按 folder 分组，本地 tab 先显示文件夹列表，点进看歌

关键点：

  • 不用全盘权限，走 MediaStore，华为也认
  • 播放用 content:// URI，不是文件路径（避开分区存储限制）
  • id 用 path（即 URI），稳定，收藏/改名不会丢

4.2 网络搜索与播放

依赖：https://yinyue.baoge456.de5.net（Cloudflare Worker）

功能接口
搜索/api/gd-music?types=search&source=netease&name=关键词&count=30&pages=1
取播放地址/api/gd-music?types=url&id=歌曲ID&source=netease&br=320
⚠️ Worker 挂了，网络 tab 全废；本地功能不受影响。

4.3 下载到本地

流程：

  1. 取播放 URL
  2. 调 Kotlin createAudioFile，用 MediaStore 创建条目，返回 content:// URI
  3. 下载数据，调 writeToUri 写入
  4. 写完后设 IS_PENDING=0，系统收录
❌ 不要在 insert 后立刻 IS_PENDING=0，否则文件还没写就被系统删，报 No item at content://...。

下载完成后，切到「本地」重新扫描即可看到。

4.4 收藏 / 隐藏 / 改名 / 改歌手

数据存储 key说明
收藏 idfavorites本地用 path，在线用 id
在线收藏歌favorite_songs存 id/标题/歌手/songmid
隐藏 idhidden从本地列表隐藏（不删文件）
自定义标题custom_titlesid → 新标题
自定义歌手custom_artistsid → 新歌手

全部存 shared_preferences。显示时优先用自定义值。

⚠️ 清除 App 存储 / 卸载 App，以上全丢。重装用 adb install -r 覆盖，别卸载。

4.5 主题系统

5 套主题：暗夜紫、深海蓝、森林绿、暖日落、浅色。顶部调色盘按钮切换，存 theme_index。

4.6 播放页

点正在播的歌 / 点底部播放条 → 进播放页。

  • 竖屏：上封面、中信息、下控制，居中
  • 横屏：左封面、右信息+控制（适合车机）
  • 控制行：[⏮] [▶️] [⏭] [🔁] 四键均分

第五部分：常见问题

Q1：编译特别慢

原因：Gradle 在走 Google 服务器。解法：

  • 配 Flutter 国内镜像（见第一部分第 6 步）
  • 改 android/settings.gradle.kts 和 android/build.gradle.kts，加阿里云镜像
  • 别频繁 flutter clean

Q2：网络搜索失败，报 Failed host lookup

检查 AndroidManifest.xml 有没有：

XML
<uses-permission android:name="android.permission.INTERNET" />

缺了它，所有联网功能全废。

Q3：扫描失败，Permission denied

华为/荣耀上，MANAGE_EXTERNAL_STORAGE 拿不到。已改用 MediaStore 查询，不需要全盘权限。

Q4：下载失败 No item at content://...

Kotlin 侧 createAudioFile 不能在 insert 后立刻 IS_PENDING=0。要等 writeToUri 写完再设。

Q5：下载失败 无法获取下载地址

某些歌网易云取不到 URL（版权/VIP）。换热门歌试。若所有歌都取不到，检查 Worker。

Q6：收藏/改名/改歌手，重开后丢了

检查是否清过 App 存储、或卸载过。用 adb install -r 覆盖安装保数据。

Q7：播放没声音，进度不动

检查播放地址。本地用 content:// URI，在线用 Worker 返回的 URL。

Q8：搜索框老弹输入法

已修：切 tab、扫描完成时主动 unfocus，搜索框 autofocus: false。

第六部分：后续扩展

6.1 网络多源备用

当前网络功能只依赖一个 Worker。可在 main.dart 里存多个 API 地址，逐个重试：

Dart
final apis = [
  'https://yinyue.baoge456.de5.net/api/gd-music',
  'https://music-api.gdstudio.xyz/api.php',
  'https://api.music.ftm.best/api.php',
];

6.2 后台播放 + 通知栏

用 audio_service 包，配合 media_kit，实现锁屏/通知栏控制。

6.3 歌词（可选）

本地：读同目录 .lrc 或内嵌歌词。在线：调 Worker 的 lyric 接口。车机上用处不大，优先级低。

6.4 车机适配

车机横屏，播放页已用左图右控布局。可加大按钮、加物理按键映射。

6.5 音效 / 均衡器

libmpv 支持 af=equalizer=...，但 media_kit 没直接暴露。手机/车机自带音效一般够用，优先级低。
