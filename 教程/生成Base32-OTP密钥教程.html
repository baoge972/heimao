🔐 生成 Base32 OTP 密钥

用于 Google Authenticator 的 TOTP 验证

1️⃣ 第一步：打开 PowerShell

在哪里运行：

在 Windows 系统上打开 PowerShell 终端

操作方法：

按 Win + X，选择 "Windows PowerShell" 或 "Windows 终端"

或按 Win + R，输入 powershell，按回车

📍 提示：无需管理员权限，普通用户模式即可

2️⃣ 第二步：生成 Base32 密钥

方法 1：简单版（推荐）
$chars = "ABCDEFGHIJKLMNOPQRSTUVWXYZ234567" $key = -join (1..20 | ForEach-Object { Get-Random -InputObject $chars.ToCharArray() }) Write-Host "Base32 密钥: $key"
方法 2：一行版
-join (1..20 | ForEach-Object { "ABCDEFGHIJKLMNOPQRSTUVWXYZ234567"[(Get-Random -Minimum 0 -Maximum 32)] })
✅ 输出示例： Base32 密钥: JBSWY3DPEHPK3PXP

密钥长度为 16-20 位，仅包含大写字母 A-Z 和数字 2-7

3️⃣ 第三步：配置 Workers 环境变量

在哪里配置：

Cloudflare Dashboard → Workers → 你的项目 → 设置 → 变量

变量名 值 说明
OTP_SECRET 生成的 Base32 密钥 如 JBSWY3DPEHPK3PXP
📍 提示：保存后需要重新部署 Workers 才能生效

4️⃣ 第四步：绑定 Google Authenticator

在手机上操作：

1. 打开 Google Authenticator 应用

2. 点击 + 号，选择 "手动输入密钥"

3. 输入以下信息：

  • 账户名称：CF-Workers（自定义）
  • 密钥：复制生成的 Base32 密钥
  • 时间类型：保持 "基于时间"

4. 点击 "添加"

✅ 成功标志：手机应用显示 6 位数字验证码，每 30 秒刷新一次

5️⃣ 第五步：测试验证

测试流程：

1. 访问你的 Workers 网站

2. 输入登录密码

3. 弹出 OTP 输入框

4. 输入手机上的 6 位验证码

5. 验证成功，登录完成 ✅

⚠️ 注意：如果提示"动态验证码错误"，检查：
  • 手机时间是否准确
  • 密钥是否正确复制（区分大小写）
  • Workers 环境变量是否已更新

❓ 常见问题

问题 解决方法
Google Authenticator 提示"密码值太短" 使用了 Base64 密钥，必须用 Base32（仅包含 A-Z 和 2-7）
动态验证码一直错误 校准手机时间，确保与网络时间同步
忘记密码怎么办 重新生成密钥，更新环境变量，重新绑定 Google Authenticator
多人使用怎么办 每人使用不同的 OTP_SECRET，分别绑定
