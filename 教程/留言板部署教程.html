📝 Cloudflare Workers 留言板 部署教程

基于 Cloudflare Workers + KV 的极简留言板。
普通用户注册后发表、删除自己的留言；管理员通过独立入口管理所有留言。

✅ 零成本 ⚡ 全球边缘网络 🔐 独立管理员 📦 KV 持久化 📌 多空间隔离

📦 准备工作

  1. 注册 Cloudflare 账号
  2. 登录 Cloudflare Dashboard
💡 提示：全程在浏览器中操作，无需安装任何工具。

🚀 部署步骤

1 创建 KV 命名空间

  1. 进入 Workers & Pages → 点击 KV 选项卡
  2. 点击 创建命名空间，输入名称（如 forum_data），点击创建
📌 关键：KV 名称任意取，绑定名称必须和代码一致（后面设置）。

2 创建 Worker

  1. Workers & Pages → 创建应用程序 → 创建 Worker
  2. 输入名称（如 lyb），点击 部署
  3. 点击 编辑代码 进入编辑器

3 绑定 KV

  1. 点击 设置 → 变量
  2. 在 KV 命名空间绑定 区域，点击 添加绑定
  3. 变量名称：FORUM；KV 命名空间：选择刚创建的
  4. 点击 保存并部署

4 设置管理员密码

  1. 在 变量 设置页面，找到 环境变量 区域
  2. 点击 添加变量：名称 ADMIN_PASSWORD，值输入您的密码
  3. 点击 保存并部署
⚠️ 记住密码！ 管理后台登录需要。

5 写入 Worker 代码

点击下方按钮，打开代码链接，复制全部内容，粘贴到 Worker 编辑器中，然后点击「保存并部署」。

📄 打开 Worker 代码
点击后在新标签页打开代码，全选复制即可

👤 用户管理

删除注册用户

在 Cloudflare Dashboard → KV 中操作，删除用户需要删除三项数据：

序号KV 键说明
1user_blog_jiguang_用户名用户信息（用户名、密码、角色）
2users_blog_jiguang用户列表（编辑移除该用户名）
3messages_blog_jiguang_用户名该用户的所有留言（含管理员回复）
⚠️ 注意：删除后不可恢复，请谨慎操作。

示例：删除用户 baoge

1. 删除用户信息
键：user_blog_jiguang_baoge
→ 点击「删除」

2. 编辑用户列表
键：users_blog_jiguang
原值：["baoge", "zhangsan"]
→ 改为：["zhangsan"]

3. 删除用户留言
键：messages_blog_jiguang_baoge
→ 点击「删除」

💡 提示：删除用户后，管理员回复会随留言一起删除，不会残留。

🔧 常见问题

忘记管理员密码？ 在 Dashboard 修改 ADMIN_PASSWORD 环境变量，重新部署。
数据会丢吗？ 不会，存储在 KV 中，重新部署不影响。
管理员能看到留言板吗？ 管理员访问 /?blog=jiguang 看到的是普通留言板（未登录状态），管理功能只在 /admin 页面。
