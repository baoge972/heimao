🚀 frpc 双 VBS 后台运行 使用教程

💡 目的： 让 frpc 在 Windows 上灵活运行，无窗口静默运行和有窗口查看日志两种模式自由切换。

📁 准备工作

确保 frpc.exe 和 frpc.toml 在同一个目录下，例如：

D:\frp\frpc.exe D:\frp\frpc.toml
⚠️ 路径不要包含中文、空格或特殊字符，否则 VBS 可能执行失败。

📄 创建两个 VBS 脚本

1 创建 run.vbs（无窗口，后台运行）

在 frp 目录下创建 run.vbs，内容如下：

' 杀掉所有 frpc 进程 CreateObject("WScript.Shell").Run "taskkill /F /IM frpc.exe", 0, True ' 杀掉所有 cmd 进程（关闭弹窗） CreateObject("WScript.Shell").Run "taskkill /F /IM cmd.exe", 0, True ' 等待 1 秒 WScript.Sleep 1000 ' 后台启动 frpc（无窗口） CreateObject("WScript.Shell").Run "D:\frp\frpc.exe -c D:\frp\frpc.toml", 0, False
✅ 双击 run.vbs，frpc 将在后台无窗口运行。
💡 如果已有弹窗，会被自动关闭。
2 创建 run-log.vbs（有窗口，显示日志）

在 frp 目录下创建 run-log.vbs，内容如下：

' 杀掉所有 frpc 进程 CreateObject("WScript.Shell").Run "taskkill /F /IM frpc.exe", 0, True ' 等待 1 秒 WScript.Sleep 1000 ' 前台启动 frpc（显示日志窗口） CreateObject("WScript.Shell").Run "cmd /k cd /d D:\frp && frpc.exe -c frpc.toml", 1, False
✅ 双击 run-log.vbs，会弹出一个 CMD 窗口，显示 frpc 的运行日志。
💡 关闭这个窗口，frpc 进程也会随之停止。

🔄 双 VBS 互锁机制

✅ 两个 VBS 可以随时切换：
双击 run.vbs → 自动关闭所有弹窗，frpc 转为后台运行
双击 run-log.vbs → 自动关闭旧 frpc，新弹窗显示日志
无需手动关闭任何窗口！

🔍 查看 frpc 进程数量

3 检查进程
tasklist | findstr frpc

正常情况下只会有 1 个 frpc 进程在运行。

🧹 手动杀掉所有 frpc 进程

4 清理进程
taskkill /F /IM frpc.exe
⚠️ 这个命令会杀掉所有 frpc 进程。杀完后，双击 run.vbs 重新启动一个。

✅ 验证 frpc 是否正常工作

5 测试端口转发
curl http://127.0.0.1:31401/health

返回 JSON 数据（如 {"database_connected":true,...}）说明 frpc 正常工作。

💡 curl 命令在 PowerShell 中可能会报错，建议在 CMD 中执行。

⚙️ 开机自启动

⚠️ 不推荐设置开机自启动，因为此时 karing 可能尚未连接，导致 frpc 连接失败。

如果确实需要，把 run.vbs 放到启动文件夹：

copy D:\frp\run.vbs "%APPDATA%\Microsoft\Windows\Start Menu\Programs\Startup\"

⚠️ 重要注意事项

🚨 核心原则：两个 VBS 脚本互锁，任意时刻只保留一个 frpc 进程。
  • 不要同时运行多个 frpc 进程。 虽然第二个进程会报错 proxy already exists 不会导致转发失败，但会浪费系统资源。
  • 切换模式时，直接双击另一个 VBS 即可。 脚本会自动清理。
  • 如果修改了 frpc.toml，需要先 杀掉进程 后重新双击对应的 VBS 才能生效。
  • 保存 VBS 时，编码必须选择 ANSI，否则中文注释会乱码导致脚本执行失败。
