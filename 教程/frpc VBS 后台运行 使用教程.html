🚀 frpc VBS 后台运行 使用教程

💡 目的： 让 frpc 在 Windows 后台静默运行，无弹窗、关掉命令行也不影响。

📁 准备工作

确保 frpc.exe 和 frpc.toml 在同一个目录下，例如：

D:\frp\frpc.exe D:\frp\frpc.toml
⚠️ 路径不要包含中文、空格或特殊字符，否则 VBS 可能执行失败。

📄 创建 run.vbs（无窗口推荐）

1 创建 run.vbs

在 frp 目录下创建 run.vbs，内容如下：

CreateObject("WScript.Shell").Run "D:\frp\frpc.exe -c D:\frp\frpc.toml", 0, False
✅ 双击 run.vbs，frpc 将在后台无窗口运行。
💡 run.vbs 中的路径必须使用 绝对路径，否则 VBS 找不到 frpc.exe。

📄 创建 start_frpc.bat（有窗口，备用）

2 创建 start_frpc.bat（可选）

在 frp 目录下创建 start_frpc.bat，内容如下：

@echo off start /b frpc -c frpc.toml exit
💡 start /b 会让 frpc 在后台运行，但会保留一个黑窗口。关掉窗口 frpc 也会停止。

🔍 查看 frpc 进程数量

3 检查进程
tasklist | findstr frpc

如果有多个 frpc 进程，说明重复启动了，需要杀掉多余的。

🧹 杀掉所有 frpc 进程

4 清理进程
taskkill /F /IM frpc.exe
⚠️ 这个命令会杀掉所有 frpc 进程。杀完后，双击 run.vbs 重新启动一个。

✅ 验证 frpc 是否正常工作

5 测试端口转发
curl http://127.0.0.1:31401/health

返回 JSON 数据（如 {"database_connected":true,...}）说明 frpc 正常工作。

💡 无论有几个 frpc 进程，只要这个命令返回正常数据，就说明转发链路是通的。
💡 curl 命令在 PowerShell 中可能会报错，建议在 CMD 中执行。

⚙️ 开机自启动（不建议采用，因为此时karing可能未启动）

6 设置开机自启

把 run.vbs 放到启动文件夹：

copy D:\frp\run.vbs "%APPDATA%\Microsoft\Windows\Start Menu\Programs\Startup\"

⚠️ 重要注意事项

🚨 核心原则：VBS 和 BAT 任选一种，不要同时使用！
  • 不要同时双击多次 run.vbs，否则会启动多个 frpc 进程，导致资源浪费。
  • 运行 VBS 后不要再运行 BAT，反之亦然。 两种方式只选一种，因为两个 frpc 同时运行虽然不会导致转发失败，但会浪费资源。 最好只留一个，杀掉多余的。
  • 如果修改了 frpc.toml，需要先 杀掉进程 后重新双击 run.vbs 才能生效。
  • 如果发现进程数超过 1 个，立即执行 taskkill /F /IM frpc.exe 清理，然后重新启动。
