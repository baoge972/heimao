🚀 Nginx 反向代理一键添加脚本

📝 自动生成配置 🔐 自动申请 SSL 证书 ⚙️ 一键部署站点 📋 所有命令可复制

基于宝哥服务器 · 系统 Nginx · 无需科技 lion

✅ 脚本功能

🔹 自动创建 Nginx 配置文件（无 quic 参数，兼容系统 Nginx）
🔹 自动申请 Let's Encrypt SSL 证书（certbot standalone 模式）
🔹 自动重载 Nginx 使配置生效
🔹 一条命令完成站点部署

1 创建脚本文件 add-site.sh
nano add-site.sh
nano add-site.sh
脚本内容（完整版）
#!/bin/bash
# 使用方法: ./add-site.sh 域名 端口
DOMAIN=$1
PORT=$2
EMAIL="admin@baoge123.de5.net"

if [ -z "$DOMAIN" ] || [ -z "$PORT" ]; then
    echo "用法: $0 域名 端口"
    echo "示例: $0 new.baoge123.de5.net 8080"
    exit 1
fi

cat > /etc/nginx/conf.d/$DOMAIN.conf << EOF
server {
    listen 80;
    server_name $DOMAIN;
    return 301 https://$server_name$request_uri;
}

server {
    listen 443 ssl http2;
    server_name $DOMAIN;

    ssl_certificate /etc/letsencrypt/live/$DOMAIN/fullchain.pem;
    ssl_certificate_key /etc/letsencrypt/live/$DOMAIN/privkey.pem;

    location / {
        proxy_pass http://127.0.0.1:$PORT;
        proxy_http_version 1.1;
        proxy_set_header Upgrade $http_upgrade;
        proxy_set_header Connection "upgrade";
        proxy_set_header Host $host;
        proxy_set_header X-Real-IP $remote_addr;
        proxy_set_header X-Forwarded-For $proxy_add_x_forwarded_for;
        proxy_set_header X-Forwarded-Proto $scheme;
    }
}
EOF

systemctl stop nginx
certbot certonly --standalone -d $DOMAIN --non-interactive --agree-tos --email $EMAIL
systemctl start nginx
nginx -t && systemctl reload nginx

echo "✅ 站点 $DOMAIN 已添加，端口 $PORT"
💡 粘贴脚本内容后，按 Ctrl+O 保存，Ctrl+X 退出。
2 添加执行权限
chmod +x add-site.sh
chmod +x add-site.sh
3 运行脚本添加新站点
基本用法
./add-site.sh 你的域名 端口号
实际示例
./add-site.sh new.baoge123.de5.net 9000
⚠️ 注意事项：
• 域名必须已解析到服务器 IP
• 后端服务已经运行在指定的端口上
• 需要使用 root 或 sudo 权限执行
• 首次执行会申请 SSL 证书，需要 80 端口空闲（脚本自动处理）

❓ 常见问题
  • Q: 提示 "Domain not found" 或证书申请失败？
    A: 确保域名已正确解析到服务器 IP，且 80 端口没有被其他程序占用。
  • Q: 执行脚本报错 "Permission denied"？
    A: 使用 sudo 执行：sudo ./add-site.sh 域名 端口
  • Q: 如何删除已添加的站点？
    A: sudo rm /etc/nginx/conf.d/域名.conf && sudo systemctl reload nginx
  • Q: 证书过期怎么办？
    A: certbot 会自动续期（每天两次检查），无需手动处理。
  • Q: 可以重复执行脚本添加多个站点吗？
    A: 可以，每次执行传入不同的域名和端口即可。
