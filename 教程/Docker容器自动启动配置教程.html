🐳 Docker Desktop 容器自动启动配置

重启策略 · always

默认情况下，Docker Desktop 中的容器不会随 Docker 引擎启动而自动运行。通过设置 --restart=always 策略，即可让容器在 Docker 启动时自动拉起，异常退出后也会自动重启。
✅ 教程提供了两种查询容器名称的方式、管理员权限提醒、一键复制命令，以及历史记录管理功能。

🔗 查询容器名称方式： 📦 DPanel 容器列表 (点击跳转) ｜ 💻 终端命令查询 (docker ps -a)
⚠️ 管理员权限提醒：请以 管理员身份运行 PowerShell / 终端，否则 Docker 命令可能权限不足。
命令格式：docker update --restart=always <容器名称> (容器名称区分大小写)

✨ 根据容器名称一键生成启动命令

docker update --restart=always 容器名称

⭐ 生成命令后会自动添加到下方「已运行历史记录」，表示该命令已配置/执行。

📖 详细配置步骤

  1. 以管理员身份打开终端 (PowerShell / CMD / 终端)：右键“Windows PowerShell”选择“以管理员身份运行”，macOS/Linux 使用 sudo 提升权限。
  2. 查询当前所有容器名称：执行 docker ps -a，复制需要自启动的容器名 (注意大小写敏感)。
  3. 执行自动重启策略命令：
    docker update --restart=always <容器名>
    例如: docker update --restart=always portainerUI
  4. 验证是否生效：重启 Docker Desktop 后，运行 docker ps 查看容器状态，或者 docker inspect <容器名> | grep -i restart

✅ 如需取消自动启动：可执行 docker update --restart=no <容器名>，并在历史记录中删除相应条目。
