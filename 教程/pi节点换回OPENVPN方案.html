🔁 换回 OpenVPN + Gost 方案 纯命令复制 · 不含注释

1 停止当前 FRP 方案 本地电脑
# 杀掉 frpc 进程
taskkill /F /IM frpc.exe
# 关闭 karing（退出程序）— 手动操作：右键托盘图标 → 退出
云服务器
# 停止 frps
systemctl stop frps
⏱️ 确保 frp 相关进程已完全退出
2 启动 Gost 云服务器
# 进入 home 目录并执行 gost 脚本，根据提示选择 4 启动 Gost
cd ~ && ./gost.sh
✅ 确认 Gost 监听端口正常 (默认 31401)
3 启动 OpenVPN 本地电脑
以管理员身份运行
  • 右键点击 OpenVPN GUI 图标 → 以管理员身份运行
  • 在系统托盘找到 OpenVPN 图标，右键 → 连接 client.ovpn
⏺ 连接状态（仅供参考，非命令） IP 分配 / 路由表 自动配置 状态: 已连接
🔒 确认 OpenVPN 隧道已建立
4 验证转发 云服务器
# 执行以下命令验证转发是否正常
curl http://127.0.0.1:31401/health
期望返回示例（仅供参考）
📤 返回示例 {"database_connected":true, ...}
✅ 若返回 database_connected: true 说明转发正常。
🧪 若返回异常，检查 Gost 及 OpenVPN 连通性
5 等待 & 观察 ⌛ 持续运行
🔄 切换网络后，在线率数据重新积累
⏳ 保持运行 24–48 小时
📈 观察奖励恢复 —— 系统需要时间统计，请耐心等待。
⭐ 若奖励未恢复，检查 client.ovpn 配置及 Gost 转发规则
