🌵 Cactus TV 部署教程

📌 目的： GitHub → Cloudflare Pages 部署
⚠️ 包含： 管理页面（/jilu）

1. 克隆项目

1 进入代码目录
cd D:\记事本
2 克隆原项目
git clone https://github.com/mo-d21/cactus-tv.git
3 进入项目文件夹
cd cactus-tv

2. ⚠️ 删除文件（必须执行）

🔥 核心操作： 删除 package.json 和 package-lock.json，防止 Cloudflare Pages 卡依赖安装。
del package.json
del package-lock.json
cactus-tv/
├── functions/
├── migrations/
├── public/
├── scripts/
├── package.json ❌ 已删除
└── package-lock.json ❌ 已删除

3. 关联你的 GitHub 仓库

git remote set-url origin https://github.com/****/cactus.git
确认：
git remote -v

4. 添加管理页面（/jilu）

创建以下 5 个文件，代码见附录：

① public/jilu.html
notepad public\jilu.html
② public/js/jilu.js
notepad public\js\jilu.js
③ functions/api/admin/history.js
notepad functions\api\admin\history.js
④ functions/api/admin/providers.js
notepad functions\api\admin\providers.js
⑤ functions/api/proxy.js
notepad functions\api\proxy.js

5. 推送代码

git add .
git commit -m "完整部署版本（含管理页面）"
git push -u origin main

6. Cloudflare Pages 部署

  • 进入： Workers & Pages → 创建 Pages 项目 → 连接 GitHub baoge6789/cactus
  • 构建设置：
    • Build command: exit 0
    • Build output directory: public
  • 环境变量：
    • ADMIN_TOKEN = 你的管理密码
    • TMDB_BEARER_TOKEN = 你的 TMDB Token
  • D1 绑定： 变量名 DB，选择你的数据库
