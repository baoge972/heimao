🐱 黑猫文件管理系统

Cloudflare Workers 完整部署教程

📋 系统简介

黑猫文件管理系统是一个基于 Cloudflare Workers 和 GitHub API 构建的轻量级文件管理工具，支持文件上传、下载、删除、搜索等功能，并提供多 CDN 加速和多主题切换。

📁 文件管理

支持上传、下载、删除文件和目录，拖拽上传，批量操作

🔐 安全验证

双重密码保护，SHA256 加密验证，环境变量安全注入

🌐 CDN 加速

支持 jsDelivr、gcore、gh-proxy 等多个 CDN，自动测速

🎨 多主题

5 种主题可选：深色、浅色、蓝色、绿色、紫色

📱 响应式设计

完美适配 PC 和移动端，流畅的交互体验

🔍 全局搜索

支持递归搜索所有目录，快速定位文件

🛠️ 前置准备

  • Cloudflare 账号：dash.cloudflare.com
  • GitHub 账号：github.com
  • 创建公开仓库：如 baoge972/heimao
  • 生成 Token：点击创建 Token → 勾选 repo 权限 → Generate token
⚠️ 立即复制 Token，关闭后无法查看

🚀 部署步骤

1 创建 Worker
  • Cloudflare Dashboard → Workers & Pages → Create application → Create Worker
  • 命名如 heimao-file → Deploy
2 配置环境变量（Settings → Variables → Add variable）
变量名示例值说明
GIT_REPObaoge972/heimao用户名/仓库名
GIT_TOKENghp_xxxGitHub Token
LOGIN_PASSWORDbaoge登录密码
ADMIN_PASSWORD_HASHd0c53f...管理员密码哈希
PASSWORD_SALTD-File-2024-Secure密码盐值
3 部署代码
  • Edit code → 粘贴 worker.js 全部内容 → Save and deploy
4 测试
  • 访问 https://heimao-file.用户名.workers.dev
  • 输入 LOGIN_PASSWORD 登录

🔧 使用指南

文件上传

  • 拖拽上传：直接将文件拖放到页面任意位置
  • 点击上传：点击「📤 上传文件」按钮选择文件
  • 批量上传：支持同时选择多个文件
💡 单个文件最大限制：100MB，超过将无法上传

目录管理

  • 创建目录：点击「📁 新建目录」，输入目录名称
  • 进入目录：点击目录名称即可进入
  • 返回上级：点击「← 返回」按钮

文件搜索

  • 在顶部搜索框输入关键词，按回车键
  • 系统会递归搜索所有子目录
  • 搜索结果会显示文件路径，方便定位

CDN 加速配置

  • 系统提供 5 个 CDN 选项：本站、jsDelivr、gcore、gh-proxy、fxxk
  • 点击 CDN 按钮会自动测试访问速度
  • 选择速度最快的 CDN（绿色标签表示速度快，红色表示速度慢）
  • 选择「本站」时会隐藏 CDN 输入框，其他选项会显示完整 URL

文件删除

  • 点击文件右侧的「删除」按钮
  • 需要输入管理员密码验证
  • 系统文件（index.html、D-file.html、CNAME、json.html）不可删除

主题切换

  • 顶部右侧有 5 个主题按钮：深色、浅色、蓝色、绿色、紫色
  • 点击即可切换，选择会自动保存

⚠️ 注意事项

⚠️ 重要提醒

  • GitHub 仓库必须是公开的，私有仓库无法通过 CDN 访问
  • Token 权限：确保 Token 有 repo 权限，否则无法上传文件
  • 文件大小限制：GitHub API 限制单个文件最大 100MB
  • CDN 缓存：上传文件后，CDN 可能需要几分钟才能同步
  • API 限制：GitHub API 有速率限制，频繁操作可能被临时封禁

💡 优化建议

  • 自定义域名：可以在 Cloudflare 中绑定自己的域名
  • 定期更新 Token：建议每 3-6 个月更新一次 GitHub Token
  • 备份重要文件：虽然 GitHub 有版本控制，但仍建议本地备份
  • 监控使用量：注意 GitHub API 调用次数，避免超出限制

🐛 常见问题

Q1：访问 Worker 显示 500 错误

原因：环境变量未配置或配置错误

解决：

  • 检查 5 个环境变量是否都已正确设置
  • 特别检查 GIT_REPO 和 GIT_TOKEN 是否正确
  • 访问 https://你的worker地址/debug-env 查看环境变量状态

Q2：上传文件失败

原因：Token 权限不足或仓库不存在

解决：

  • 确认 Token 有 repo 权限
  • 确认 GIT_REPO 格式正确（用户名/仓库名）
  • 确认仓库已创建且为公开仓库

Q3：CDN 访问文件 404

原因：CDN 缓存未更新或分支不是 main

解决：

  • 等待几分钟让 CDN 缓存更新
  • 确认你的仓库默认分支是 main（不是 master）
  • 尝试刷新 CDN 缓存或切换其他 CDN

Q4：密码错误无法登录

解决：

  • 确认输入的 LOGIN_PASSWORD 与环境变量设置的一致
  • 如果忘记了，可以在 Cloudflare Dashboard 重新设置

Q5：删除文件时密码验证失败

原因：管理员密码哈希值不匹配

解决：

  • 默认管理员密码哈希值对应密码：admin123
  • 如需自定义，使用公式：SHA256(PASSWORD_SALT + 你的密码)
  • 可以在浏览器控制台生成新的哈希值

📊 系统架构

工作流程：

  1. 用户访问 Worker URL → Cloudflare 返回管理面板 HTML
  2. 用户登录验证 → 比对 LOGIN_PASSWORD
  3. 文件操作 → 通过 GitHub API 读写仓库文件
  4. 文件访问 → Worker 代理 GitHub 文件内容，或直接通过 CDN 访问

🔒 安全说明

  • 密码存储：登录密码通过环境变量注入，不硬编码在代码中
  • 管理员验证：敏感操作（删除文件）需要二次密码验证
  • 密码加密：使用 SHA256 + Salt 哈希验证，不存储明文
  • Token 安全：Token 存储在 Cloudflare 环境变量中，前端无法直接获取
