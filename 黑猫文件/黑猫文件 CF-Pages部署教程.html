🚀 黑猫文件管理系统 CF-Pages 部署教程

1准备文件

本目录下已有优化好的 黑猫文件-hash.html（已修复滚动问题+完善删除逻辑）

💡 说明：上传到 GitHub 时需命名为 index.html，该文件已集成所有功能（登录验证、5主题、CDN测速、文件管理等），无需其他依赖文件

2创建 GitHub Token

目标

生成访问 GitHub API 的令牌（必需权限：public_repo）

操作

  1. 打开 GitHub Token 创建页面
  2. Token 名称填写：D-File Pages
  3. 过期时间选择：No expiration（或按需选择）
  4. 勾选权限：public_repo（公开仓库访问）
  5. 滚动到底部点击 Generate token
  6. ⚠️ 立即复制 Token（格式：ghp_xxxxxxxxxxxx，只显示一次）
⚠️ 重要：Token 生成后只显示一次，务必立即复制保存到安全位置！

3创建 GitHub 仓库

目标

创建一个新的 GitHub 仓库用于托管文件

操作

  1. 打开 https://github.com/new
  2. 填写仓库名称（如 dfile-pages）
  3. 选择 Public（公开仓库）
  4. 勾选 Add a README file
  5. 点击 Create repository

4上传 index.html

目标

将单文件上传到仓库根目录

操作

  1. 打开刚创建的 GitHub 仓库
  2. 点击 Add file → Upload files
  3. 将 黑猫文件-hash.html 的内容保存为 index.html
  4. 填写 Commit message（如 "初始部署"）
  5. 点击 Commit changes
✅ 完成标志：仓库根目录能看到 index.html 文件

5Cloudflare Pages 部署

目标

在 Cloudflare 绑定仓库，自动部署 Pages

操作

  1. 打开 Cloudflare Dashboard
  2. 左侧菜单点击 Workers & Pages
  3. 点击 Create application → 选择 Pages 标签
  4. 点击 Connect to Git
  5. 授权 GitHub 账号 → 选择刚创建的仓库
  6. 配置部署设置：
    • Production branch: main
    • Build command: 留空（纯静态无需构建）
    • Build output directory: 留空（默认根目录）
  7. 点击 Save and Deploy
⏱️ 预计耗时：首次部署约 1-2 分钟

6访问与配置

目标

验证部署成功并配置 GitHub Token

操作

  1. 部署完成后，CF 会生成域名：https://你的项目名.pages.dev
  2. 浏览器打开该域名 → 应看到登录界面
  3. 输入密码 baoge 登录
  4. 点击 ⚙️ 配置 → 输入仓库地址和 GitHub Token
  5. 点击 💾 保存配置 → 页面自动刷新
  6. 应能看到仓库文件列表
⚠️ 重要：GitHub Token 需要 public_repo 权限
创建地址：https://github.com/settings/tokens/new

7后续更新

目标

修改代码后自动重新部署

操作

  1. 在 GitHub 仓库中点击 index.html
  2. 点击右上角 ✏️ Edit 按钮
  3. 修改代码内容
  4. 填写 Commit message → 点击 Commit changes
  5. Cloudflare Pages 会自动检测推送并在 30 秒内重新部署
✅ 自动部署：每次 Commit 都会触发 Pages 重新构建，无需手动操作

🔐 安全配置说明

1. 登录密码修改

编辑 index.html 第 997 行：

const LOGIN_PASSWORD = "baoge"; // 修改为你的密码

2. 删除密码哈希计算（SHA256+Salt）

文件使用哈希验证删除操作，修改密码需要重新计算哈希值：

  1. 打开浏览器控制台（F12）
  2. 粘贴以下代码并回车：
// 复制运行，输入你的密码，生成哈希值
async function generateHash(password) {
    const SALT = "D-File-2024-Secure";
    const msgBuffer = new TextEncoder().encode(SALT + password);
    const hashBuffer = await crypto.subtle.digest('SHA-256', msgBuffer);
    const hashArray = Array.from(new Uint8Array(hashBuffer));
    const hashHex = hashArray.map(b => b.toString(16).padStart(2, '0')).join('');
    console.log("你的密码哈希值：", hashHex);
    return hashHex;
}
generateHash("你的新密码");
  • 将输出的哈希值替换到 index.html 第 1054 行：
    • const CORRECT_PASSWORD_HASH = "你的哈希值";
    💡 提示：登录密码（第 997 行）和删除密码（第 1054 行）可以不同，建议分别设置

    3. 盐值修改（可选）

    增强安全性，可修改盐值（第 1047 行）：

    const PASSWORD_SALT = "自定义盐值"; // 修改后需重新计算哈希

    📋 常见问题

    Q1: 访问显示 404？

    检查仓库根目录是否有 index.html 文件

    Q2: 登录失败？

    默认密码为 baoge（区分大小写）

    Q3: 文件列表加载失败？

    检查 GitHub Token 是否有效，权限是否包含 public_repo

    Q4: 如何自定义域名？

    在 Cloudflare Pages 设置 → Custom domains → 添加你的域名
