📤 步骤 1：上传 HTML 文件到 VPS

你的 HTML 文件需要放在 VPS 的某个目录里，Caddy 才能读取并展示。

  • ① 在 VPS 上创建存放目录
    📁 创建目录命令 
    sudo mkdir -p /var/html
    💡 /var/html 是示例路径，你可以改成任何你喜欢的路径，比如 /home/baoge/myweb
  • ② 上传 HTML 文件到该目录
    🖥️ 方法A：scp 命令 (macOS/Linux 本地执行) 
    scp /本地/index.html root@你的VPS公网IP:/var/html/
    🖥️ 方法B：rsync 命令 (批量上传文件夹) 
    rsync -avz --progress /本地/网站文件夹/ root@你的VPS公网IP:/var/html/
    💡 Windows 用户：使用 WinSCP、Xftp 或 1Panel 面板的文件管理，直接拖拽上传。
    💡 上传后可以用 ls -la /var/html/ 确认文件是否在。
  • ③ 设置正确的文件权限
    🔧 让 Caddy 能读取文件 
    sudo chown -R www-data:www-data /var/html
sudo chmod -R 755 /var/html

📥 步骤 2：安装 Caddy（如未安装）

如果还没安装 Caddy，复制以下命令执行。

🚀 一键安装 Caddy 
sudo apt install -y debian-keyring debian-archive-keyring apt-transport-https
curl -1sLf 'https://dl.cloudsmith.io/public/caddy/stable/gpg.key' | sudo gpg --dearmor -o /usr/share/keyrings/caddy-stable-archive-keyring.gpg
curl -1sLf 'https://dl.cloudsmith.io/public/caddy/stable/debian.deb.txt' | sudo tee /etc/apt/sources.list.d/caddy-stable.list
sudo apt update && sudo apt install caddy -y
caddy version
